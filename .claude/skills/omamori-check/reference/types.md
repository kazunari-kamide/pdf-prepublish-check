# 型ごとの「どこを見るか・どう確かめるか・正しい直し方」

コマンドの道具（`cli/omamori.ts`）を動かせない環境で、利用者が自分の PDF を確かめる手順を案内するための資料です。

**この資料だけで案内するときも、PDF・写真・Office のファイルを開かない・読まない。中身や字を会話に入れない。**
- 確かめるのは利用者です。利用者が、自分の PDF の閲覧ソフトやアプリで、下の「見分け方」の場所を開いて見ます。
- 利用者が見つけた字や値を、会話に貼ってもらう必要はありません。「あった／なかった」と、ページの番号だけで足ります。
- この資料で案内しても、道具で調べたことにはなりません。「確かめました」「安全です」と言わず、「この手順で確かめる所」として伝えます。
- 見つけられるのは、ここに並べた型だけです。すべての漏れを並べたものではありません。

## 出どころと、型の番号

- 中身は、このリポジトリにあるものだけから作りました。新しく調べて足したものはありません。
  - P1〜P12：サイトの記事（`src/site/articles.ts`）の「見分け方」「正しい直し方」の節を、そのまま写しました。
  - 黒塗りのそばの記号（P6 の仲間）：`rules/barcode-scan/README.md` から作りました。
  - P13【仮】：`README.md` の型の一覧と、`rules/pii/README.md` から作りました。
- 型の番号と名前は、`README.md` の「何を調べるか（型の一覧）」と、検出ルールの一覧（`src/inspect/rules.ts`）にそろえています。記事やルールが変わったら、ここも直します。
- 「検査のページでは…」とある所は、ブラウザの検査器（`https://omamoripdf.com/check`。PDF はブラウザの外に送らない）を、利用者が自分で使える場合の話です。

| 番号 | 型 | 何が残るか |
|---|---|---|
| P1 | 文書情報 | 作成者・タイトル・作成ソフトなどの欄 |
| P2 | XMP メタデータ | 埋め込まれたメタデータの中の作成者・編集の履歴 |
| P3 | ほかの団体の名前 | 流用した様式の、元の団体の名前 |
| P4 | ファイルの保存先 | 作ったパソコンの利用者名・職場のサーバーの場所 |
| P5 | 旧版の残存 | 上書きの前の版 |
| P6 | 見せかけの黒塗り | 黒い四角の下の文字・画像 |
| P7 | 隠れたテキスト | 白い文字・ページの外の文字・表示を切ったレイヤー |
| P8 | 注釈・コメント | コメントの中身と、付けた人の名前 |
| P9 | 添付ファイル | 埋め込まれた元の Excel・Word など |
| P10 | 画像の位置情報など | 写真の撮影場所・機種・日時 |
| P11 | フォームの入力値 | 入力欄に入ったままの値 |
| P12 | スクリプト・外部動作 | 開いたときに動くスクリプト（漏れではなく、安全上の注意） |
| P13【仮】 | 個人情報らしい字 | 見える文字の中の、氏名・住所・電話番号などらしい字 |

## P1 文書情報

検出ルール：`p1-info`

### 文書情報に、作った人の名前が残る

PDF には、作成者・タイトルなどの「文書情報」が入ります。ここに職員の個人名や、別の会社の名前が残ることがあります。

記事：https://omamoripdf.com/articles/p1-docinfo

**見分け方**

- PDF を開くアプリで「プロパティ」（「文書のプロパティ」など）を開きます。作成者・タイトル・サブタイトル・キーワードを見ます。
- 作成者が個人の名前なら、公開してよいかを確かめます。課の名前で足りるなら、書き換えます。
- 検査のページでは、文書情報の欄を、値ごと一覧にして見せます。

**正しい直し方**

- 元の Word などのファイルで、作成者の欄を消すか、課の名前に書き換えます。そのあとで PDF にします（手順は「Word で作る書類」の記事）。
- PDF しか手元にないときは、プロパティを編集できるアプリで消します。消したら、もう一度プロパティを開いて確かめます。
- 作成者の名前を、決まりで残している場合もあります。消す前に、残す決まりがないかを確かめてください。

## P2 XMP メタデータ

検出ルール：`p2-parts`・`p2-xmp`・`props-diff`・`xmp-thumbnail`

### XMP メタデータに、編集の履歴が残る

PDF には、文書情報とは別に XMP というメタデータが入ることがあります。作成者や、編集の履歴・元のファイルの情報が残ることがあります。

記事：https://omamoripdf.com/articles/p2-xmp

**見分け方**

- アプリによっては、プロパティの画面の「追加のメタデータ」などで XMP を見られます。見られないアプリもあります。
- 検査のページでは、文書情報と XMP の欄を並べて見せます。2つで値が食い違う所も知らせます。

**正しい直し方**

- 元のファイルで作成者などを消してから、PDF にし直すのが確かです。
- PDF を書き出す画面に「メタデータを含めない」などの選択があれば、選びます。名前や場所は、アプリの版によって違います。
- 直したあと、文書情報と XMP の両方に残っていないかを、もう一度確かめます。

### 貼り付けた画像や部品に、別の XMP が残る

PDF 全体の XMP とは別に、貼り付けた画像やロゴの部品にも XMP が付くことがあります。元の作成者や、元のファイルの場所が残ることがあります。

記事：https://omamoripdf.com/articles/p2-parts-xmp

**見分け方**

- 部品の XMP は、プロパティの画面には出ません。ふつうの画面では、ほとんど見えません。
- 検査のページは、部品の XMP の中の人名らしい欄や保存先も調べます。

**正しい直し方**

- 画像は、貼る前に「書き出し」などで保存し直します。そのとき、メタデータを含めない設定を選びます。
- 元のファイルの画像を、保存し直した画像に差し替えてから、PDF を作り直します。
- 直したあと、もう一度、検査のページで確かめます。

## P3 ほかの団体の名前

検出ルール：`p3-orgs`

### ほかの団体の名前が、タイトルなどに残る

ほかの団体の様式を元に書類を作ると、タイトルや文書情報に、元の団体の名前が残ることがあります。

記事：https://omamoripdf.com/articles/p3-foreign-org

**見分け方**

- プロパティの画面で、タイトル・サブタイトル・会社名を見ます。
- PDF をブラウザで開いたときに、タブに出る名前も見ます。
- 検査のページのプロパティの一覧では、団体名らしい語に印が付きます。自分の団体の名前かどうかは、目で確かめてください。

**正しい直し方**

- 元のファイルのプロパティで、タイトル・会社名などを書き換えます。そのあとで PDF にします。
- 様式を流用すること自体が悪いわけではありません。残った名前で、誤解を招かないようにするためです。

## P4 ファイルの保存先

検出ルール：`p4-paths`

### 作ったパソコンの場所（ファイルの保存先）が残る

PDF の中に、作ったパソコンの利用者名や、職場のサーバーのフォルダの場所が、文字として残ることがあります。

記事：https://omamoripdf.com/articles/p4-internal-path

**見分け方**

- プロパティの画面で、タイトルなどに保存先が入っていないかを見ます。
- 部品の中や、リンクの行き先に残ったものは、ふつうの画面では見えません。
- 検査のページは、文書情報・XMP・注釈・リンクの行き先の中の保存先を探します。

**正しい直し方**

- 元のファイルのタイトルなどを書き換えます。そのあとで、印刷ではなく「PDF として保存」「エクスポート」で PDF にします。
- 共有フォルダへのリンクは、公開する書類からは外します。
- 画像は、保存し直してから貼ると、元の場所の情報が残りにくくなります（アプリによって違います）。

## P5 旧版の残存

検出ルール：`p5-revisions`・`unused-images`・`extras`

### 修正する前の版が、ファイルの中に残る

PDF を上書きで保存すると、直す前の中身がファイルの中に残ることがあります。差し替える前の金額や名前が分かるおそれがあります。

記事：https://omamoripdf.com/articles/p5-revisions

**見分け方**

- ふつうの画面では分かりません。調べる道具で、保存が何回分重なっているかを見ます。
- 検査のページでは、前の版が残っていることと、その場所を知らせます。
- 前の版が残っていても、消したい中身が入っているとは限りません。中身は、元のファイルと見比べて決めます。

**正しい直し方**

- 元の Word などのファイルを直して、PDF を作り直すのが確かです。
- PDF のアプリで直すときは、上書きではなく「名前を付けて保存」で、新しいファイルにします。
- アプリによっては、それでも前の版が残ります。保存したあと、もう一度確かめてください。

### 消したページや使わない部品が、ファイルの中に残る

PDF のアプリでページを消しても、そのページの中身がファイルに残ることがあります。表示されない部品の中に、字が残ることもあります。

記事：https://omamoripdf.com/articles/p5-removed-page

**見分け方**

- ふつうの画面では分かりません。ページ数を数えても分かりません。
- 検査のページは、どこからも使われていない中身や、描かれない部品を探して知らせます。

**正しい直し方**

- 元のファイルから要らないページを消し、PDF を作り直すのが確かです。
- PDF のアプリで直すときは、残すページだけを新しいファイルに書き出します（「ページの抽出」など）。
- 書き出したあと、もう一度、検査のページで確かめます。

### ページの縮小画像に、直す前のページが残る

PDF には、ページの縮小画像（サムネイル）を入れておけます。ページを直しても、古い縮小画像がそのまま残ることがあります。

記事：https://omamoripdf.com/articles/p5-thumbnail

**見分け方**

- アプリの縮小画像の一覧は、その場で描き直したものなので、当てになりません。
- 検査のページは、ページに縮小画像が入っているかを調べて知らせます。

**正しい直し方**

- PDF を作るときに、縮小画像を入れない設定にします（アプリの版によって、名前や場所が違います）。
- 入っている縮小画像は、アプリの機能で消すか、元のファイルから PDF を作り直します。

## P6 見せかけの黒塗り

検出ルール：`p6-text`・`barcode-scan`

### 見せかけの黒塗り：黒い四角の下に、文字が残る

黒い四角を上に重ねただけの黒塗りでは、下の文字がそのまま残り、コピーや検索で取り出せます。スキャンした画像の上に重ねた場合も、下の画像が残ります。

記事：https://omamoripdf.com/articles/p6-fake-redaction

**見分け方**

- 黒塗りの所をドラッグして選び、コピーします。メモ帳などに貼り付けて、文字が出てきたら、残っています。
- PDF のアプリの検索で、隠したはずの言葉を探してみます。
- ただし、何も出なくても、残っていないとは言い切れません。画像の中の字は、コピーでは分かりません。
- 検査のページは、黒い覆いの下の字と、覆いの下の画像を調べます。

**正しい直し方**

- PDF のアプリの「墨消し」の機能を使い、下の文字ごと消します（手順は「Acrobat の墨消し」の記事）。
- Word で作る書類なら、隠す文字そのものを消して「■■■」などに置き換えます。そのあとで PDF にします。
- スキャンの書類なら、紙の段階で塗るか、画像そのものを塗ってから PDF にします（手順は「スキャンの書類」の記事）。

### 白い四角で隠した下に、文字や画像が残る

白い四角や白い注釈を上に重ねて消したように見せても、下の文字や画像は残ります。黒塗りと同じく、コピーや取り出しで中身が分かります。

記事：https://omamoripdf.com/articles/p6-white-box

**見分け方**

- 何もないように見える所をドラッグして選び、コピーします。メモ帳などに貼り付けて、文字が出てこないかを見ます。
- 検査のページは、白い覆いの下の字と、覆いの下の画像を調べます。

**正しい直し方**

- 元のファイルで、その文字や画像を消してから PDF にします。
- PDF しか手元にないときは、墨消しの機能で消します（手順は「Acrobat の墨消し」の記事）。

### 墨消しの印を付けただけで、適用していない

PDF のアプリの墨消しは、印を付けたあとに「適用」を押したときに、下の文字が消えます。印を付けただけで保存すると、下の文字は残ります。

記事：https://omamoripdf.com/articles/p6-unapplied-redaction

**見分け方**

- PDF のアプリの注釈の一覧に、墨消しの印が残っていないかを見ます。
- 印の所をドラッグして選び、コピーして、文字が出てこないかを見ます。
- 検査のページは、適用していない墨消しの印の下の字を調べます。

**正しい直し方**

- 墨消しの機能で「適用」を押してから、「名前を付けて保存」で新しいファイルにします（手順は「Acrobat の墨消し」の記事）。
- 印だけの版は、確かめ用として外に出さないように、ファイルの名前などで分けておきます。

### 黒塗りのそばに、機械で読む記号が塗られずに残る【仮】

スキャンした書類で、宛名などを黒く塗っても、そのそばの、細い縦の線がそろった間隔で並ぶ記号（郵便の宛先や管理番号を表す、機械で読む記号）が塗られずに残っていることがあります。記号から、塗った情報を読み取られるおそれがあります。

出どころ：`rules/barcode-scan/README.md`（記事はまだありません）

**見分け方**

- 黒く塗った所の上下（目安として 1 インチほど）に、細い縦の線が 12 本以上、そろった間隔で並ぶ記号がないかを、閲覧ソフトで拡大して見ます。
- 線の高さが 1〜4 種類で並ぶ形が目安です。

**正しい直し方**

- 記号の列も、塗った情報と同じく塗ります。記号まで覆ったものは、この型に当たりません。
- スキャンした書類の塗り方は、下の「手順の記事」の、スキャンした書類の記事に従います。

## P7 隠れたテキスト

検出ルール：`p7-hidden`・`alt-text`・`font-glyphs`・`font-glyphs-cff`

### 見えないのに、検索やコピーで出てくる文字

白い文字やページの外に置いた文字は、画面では見えません。それでも PDF の中に残り、検索やコピーで取り出せることがあります。

記事：https://omamoripdf.com/articles/p7-hidden-text

**見分け方**

- ページ全体を選んで（Ctrl＋A など）コピーします。メモ帳などに貼り付けて、見覚えのない文が出てこないかを見ます。
- PDF のアプリの「レイヤー」の一覧に、表示を切った層がないかを見ます。
- 検査のページは、白い字・とても小さい字・ページの外の字・表示を切った層の字などを調べます。

**正しい直し方**

- 見えなくするのではなく、元のファイルで、その文字を消してから PDF にします。
- レイヤーは、要らない層を消すか、PDF にするときに「見えている層だけを書き出す」を選びます（アプリの版によって、名前や場所が違います）。

### スキャンした書類の上に、見えない文字の層がある

文字を読み取る機能（OCR）をかけたスキャンの PDF には、画像の上に見えない文字の層が入ります。画像だけを塗っても、この層の字は残ります。

記事：https://omamoripdf.com/articles/p7-ocr-layer

**見分け方**

- スキャンした PDF で、文字を選べるか、検索で言葉が見つかるかを試します。できれば、文字の層があります。
- 検査のページは、文字の層のあるページを「お知らせ」として示します。それだけでは漏れとは数えません。

**正しい直し方**

- 黒塗りする書類は、読み取りをかける前に塗るか、紙の段階で塗ります（手順は「スキャンの書類」の記事）。
- 読み取りをかけたあとに隠すなら、墨消しの機能で、画像と文字の層の両方を消します。
- 検索できなくてよい書類なら、読み取りをかけない設定で、スキャンし直します。

### しおり（目次）の題に、古い見出しや名前が残る

PDF の「しおり」は、ページへ飛ぶための目次です。本文を直しても、しおりの題が古いまま残り、消した見出しや名前が見えることがあります。

記事：https://omamoripdf.com/articles/p7-bookmark-title

**見分け方**

- PDF のアプリで、しおりの一覧（「ブックマーク」など）を開いて、全部の題を読みます。
- 閉じたしおりの下にも、題が隠れていることがあります。開いて確かめます。
- 検査のページは、しおりの題があることを、確認してほしい所として示します。

**正しい直し方**

- 元のファイルの見出しを直してから、PDF を作り直します。
- PDF のアプリで直すときは、しおりの題を書き換えるか、要らないしおりを消します。

### 図の代わりの説明（代替テキスト）に、見せない情報が残る

図や写真には、読み上げのための「代わりの説明」を付けられます。画面には出ないので、写った人の名前や下書きの文が残っていても気づきにくくなります。

記事：https://omamoripdf.com/articles/p7-alt-text

**見分け方**

- Word では、図を右クリックして「代替テキストを表示」などで、付いた説明を見られます。
- PDF になったあとは、ふつうの画面では見えません。
- 検査のページは、代わりの説明があることを、確認してほしい所として示します。

**正しい直し方**

- 元のファイルで、図ごとに説明を読み、見せてよい文に直します。そのあとで PDF にします。
- 説明そのものは消さずに、図の中身が分かる短い文にしておくと、読み上げで使う人にも役立ちます。

### 切り抜いた写真の外側や、ページの外の画像が残る

写真を切り抜いて貼っても、切った外側の部分がファイルに残ることがあります。ページの外に置いた画像も、見えないだけで残ります。

記事：https://omamoripdf.com/articles/p7-hidden-image

**見分け方**

- Word では、写真を選んで「トリミング」を押すと、切った外側が薄く見えます。
- PDF になったあとは、ふつうの画面では分かりません。
- 検査のページは、ページの外の画像や、大部分を切り抜いた画像を調べます。

**正しい直し方**

- Word では「図の圧縮」で「図のトリミング部分を削除する」を選んでから、PDF にします。
- 写真のアプリで切り抜いて保存し直した画像を、貼り直す方法もあります。
- ページの外へずらした画像は、消してから PDF にします。

## P8 注釈・コメント

検出ルール：`p8-annot`

### 注釈・コメントの中身が、そのまま公開される

PDF に付けた付箋・コメント・ハイライトなどを注釈と呼びます。確認のやりとりの中身が、そのまま公開されることがあります。

記事：https://omamoripdf.com/articles/p8-annotation

**見分け方**

- PDF のアプリの「注釈」や「コメント」の一覧を開き、残っているものがないかを見ます。
- 検査のページは、隠す設定の注釈や、注釈の見た目の中だけにある字も調べます。

**正しい直し方**

- 要らない注釈は、一覧から消してから保存します。
- 残したい書き込みは、元のファイルの本文に書き込んでから PDF にします。
- 消したあとに上書きすると、前の版（P5）に注釈が残ることがあります。「名前を付けて保存」で新しいファイルにします。

### 注釈に、付けた人の名前が残る

注釈には、付けた人の名前の欄があります。アプリがパソコンのログイン名を自動で入れるため、確認した職員の名前が公開されることがあります。

記事：https://omamoripdf.com/articles/p8-annotation-author

**見分け方**

- 注釈の一覧で、それぞれの注釈の「作成者」を見ます。注釈のプロパティでも見られます。
- 検査のページは、注釈の作成者の欄に名前があることを知らせます。

**正しい直し方**

- 要らない注釈は消します。
- 残す注釈は、プロパティで作成者を課の名前などに書き換えます。
- アプリの設定で、注釈に入れる名前を、課の名前などに変えておきます（アプリの版によって、名前や場所が違います）。

## P9 添付ファイル

検出ルール：`p9-attach`

### 添付ファイルが、PDF の中に入ったままになる

PDF には、別のファイルを埋め込めます。元の Excel や Word が入ったまま公開されると、隠したはずの列や、計算の元のデータまで見られることがあります。

記事：https://omamoripdf.com/articles/p9-attachment

**見分け方**

- PDF のアプリで、クリップの形の印や「添付ファイル」の一覧を見ます。
- 注釈の形で、ページの上に付いている添付ファイルもあります。
- 検査のページは、添付ファイルの有る・無しを調べます。一覧に出ない添付ファイルも調べます。

**正しい直し方**

- 要らない添付ファイルは、一覧から消します。そのあと「名前を付けて保存」で新しいファイルにします。
- PDF を作る設定で、元のファイルを添付しないようにします（アプリの版によって、名前や場所が違います）。

### 添付した PDF の中にも、同じ残り方がある

PDF に添付した別の PDF や文書の中にも、作成者の名前・注釈・見えない文字が残ることがあります。外側の PDF を確かめただけでは分かりません。

記事：https://omamoripdf.com/articles/p9-attachment-inside

**見分け方**

- 添付ファイルの一覧から、1つずつ取り出して開きます。中も、ほかの記事と同じ方法で確かめます。
- 検査のページは、添付が PDF なら、その中も調べます。文字のファイルなら、字があることを知らせます。

**正しい直し方**

- 添付が要らなければ、消します。
- 要るなら、添付するファイルを先に直してから、添付し直します。
- 添付せずに、別のファイルとして公開する方法もあります。そのファイルも、公開の前に確かめます。

## P10 画像の位置情報など

検出ルール：`p10-exif`

### 写真に、撮った場所や機種の情報が残る

スマートフォンなどで撮った写真には、撮った場所（位置情報）・機種・日時が入っていることがあります。PDF に貼ると、その情報も一緒に入ることがあります。

記事：https://omamoripdf.com/articles/p10-image-exif

**見分け方**

- 貼る前の写真のファイルで、プロパティの「詳細」などを開き、位置情報や機種を見ます。
- PDF に入ったあとの写真の情報は、ふつうの画面では見えません。
- 検査のページは、PDF の中の写真の位置情報・機種・撮った人の欄を調べます。

**正しい直し方**

- 貼る前に、写真の位置情報などを消します（手順は「写真を貼る前に」の記事）。
- スマートフォンの設定で、写真に位置情報を入れないようにできます。

### 写真の中の小さな見本に、切る前・塗る前の絵が残る

写真のファイルの EXIF には、小さな見本の画像が入ることがあります。写真を切り抜いたり塗ったりしても、見本の方は元のままのことがあります。

記事：https://omamoripdf.com/articles/p10-photo-thumbnail

**見分け方**

- ふつうの画面では、見本は見えません。
- 検査のページは、PDF の中の写真に見本があるかと、本体と形が違うかを調べます。

**正しい直し方**

- 写真は、直したあとに、撮った時の情報を含めない設定で書き出し直してから貼ります（手順は「写真を貼る前に」の記事）。
- 書き出し直した写真でも、もう一度、検査のページで確かめます。

## P11 フォームの入力値

検出ルール：`p11-forms`

### フォームの欄に、入れた値が残る

入力できる欄のある PDF（フォーム）に値を入れたまま公開すると、記入例のつもりの値や、前に入れた人の値が残ることがあります。

記事：https://omamoripdf.com/articles/p11-form-value

**見分け方**

- PDF のアプリで、入力できる欄を1つずつ見ます。欄を選ぶと、全部の値が見えることがあります。
- 検査のページは、フォームの欄の値を、見え方ごとに調べます。

**正しい直し方**

- 公開する様式は、値を全部消してから保存します。アプリに「フォームをリセット」などの機能があれば使います。
- 記入例は、架空の名前・番号（山田太郎、○○市 など）で作ります。

### 見えない欄・ページにない欄に、値が残る

フォームには、画面に出ない欄や、どのページにも置かれていない欄を作れます。そこに入った値は、欄を1つずつ見ても見つかりません。

記事：https://omamoripdf.com/articles/p11-hidden-field

**見分け方**

- PDF のアプリのフォームを編集する画面で、欄の一覧を見ます。画面に出ていない欄も、一覧には出ることがあります。
- 検査のページは、見えない欄や、ページにない欄の値も調べます。

**正しい直し方**

- フォームを編集する画面で、要らない欄を消します。
- 残す欄は、「フォームをリセット」などで値を消してから保存します。
- 保存は「名前を付けて保存」で新しいファイルにします。上書きすると、前の版（P5）に値が残ることがあります。

## P12 スクリプト・外部動作

検出ルール：`p12-actions`

### スクリプト・外へつなぐ動き（受け取る人のための注意）

PDF には、開いたときに動くスクリプトや、ほかのプログラム・ウェブのページを開く動きを入れられます。漏れではありませんが、要らなければ外します。

記事：https://omamoripdf.com/articles/p12-active-content

**見分け方**

- PDF のアプリの、スクリプトやアクションの一覧で見ます（一覧がないアプリもあります）。
- 受け取った PDF で、開いたときに注意が出る場合は、入っているかもしれません。
- 検査のページは、開いたときなどに自動で動くスクリプトや動きを調べます。

**正しい直し方**

- 計算などに要らないなら、スクリプトやアクションを外してから公開します。
- 要る場合は、何のためのものかを書類の説明に書いておくと、受け取った人が判断できます。

## P13【仮】 個人情報らしい字

検出ルール：`pii`

見える文字の中の、氏名・住所・電話番号・マイナンバー・口座番号・生年月日・メールアドレス・カード番号などらしい字です。漏れと決まったものではなく、**黒塗りの候補**です。

**見分け方**

- 公開・提出する範囲で、氏名・住所・電話番号などが見える所に残っていないかを、利用者がページごとに見ます。
- 表の見出し（「氏名」「住所」など）や、「様」などの呼び方の近くは、特に確かめます。
- スキャンした書類の上の、見えない文字の層（P7）にも、同じ字が入っていることがあります。

**正しい直し方**

- 黒塗りにするかは、利用者が決めます。お守りPDF は、この型を「整える」では消しません。
- 塗ると決めた所は、作ったソフトの墨消しの機能で、下の字まで消します（手順は下の「手順の記事」の、Acrobat の墨消し・スキャンした書類の記事）。検査のページを使えるなら、自分で黒塗りする所を選べます。
- 塗ったあとに、P6（見せかけの黒塗り）の見分け方で、下の字が残っていないかを確かめます。
