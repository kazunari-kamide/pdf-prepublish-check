# 動画の素材：架空の市の会議録（スキャンの形）

動画の最初の場面で使う、合成の PDF です。**中身はすべて架空で、このリポジトリで作ったものです。** 実在の役所・人・住所・ロゴは使っていません。市の名前（白樺野市）・町の名前（星見台町）・マークも架空です（実在しないことは、すべての市区町村・町名と照らしてはいません）。

採点に使う `fixtures/` には入れていません（ここは動画の素材の置き場です）。

## 出すもの

| ファイル | 中身 |
|---|---|
| `scan-minutes.pdf` | 会議録の 1 ページ。ページ全体が 1 枚のスキャンの画像（JPEG）で、字の層はない。申請者の名前・住所・理由の上に、黒く塗った四角の注釈（Square）が 3 つ重なっている（`fixtures/p6/p6-i03` と同じ型） |
| `scan-minutes-synthetic.pdf` | 上と同じで、左下の隅に小さく「合成のテスト用PDF（中身はすべて架空です）」と入れた版 |
| `scan-minutes-uncovered.jpg` | 黒い四角を外した版（下が見える版）の画像。PDF の中の画像と 1 バイトも違わない |
| `scan-minutes-synthetic-uncovered.jpg` | 隅の一言を入れた版の、黒い四角を外した画像 |
| `scan-minutes-large.pdf` | 大きい版（撮影で「3MB 以下」に縮める所を見せるため）。同じ会議録を 300 dpi・カラーの細かいスキャンにし、参考資料（架空の要綱の抜粋・審査の基準）の 2 ページを足した 3 ページ。約 6.4MB（6,417,901 バイト）。黒い四角の注釈は 1 ページめにだけ、上の版と同じ場所（pt）に 3 つ |
| `scan-minutes-large-synthetic.pdf` | 大きい版の、どのページにも隅の一言を入れた版（6,441,010 バイト） |
| `boxes.json` | 黒い四角の場所。画像のピクセル（左上が 0）と、PDF の場所（pt、左下が 0）の両方。動画で「黒い四角をシールのようにつまんで横にずらす」場面の位置合わせに使う |
| `build.mjs` | 作り方の道具 |

黒い四角の下の画像に写っている字（架空）：「山田太郎」「星見台町1-2-3」「理由：借金の返済のため」。

## 作り直し方

```
node demo/scan-minutes/build.mjs
```

- 手元の Chrome（headless）を使う。場所は `CHROME_PATH` で変えられる。
- 書体は `design/fonts/source/` の Noto Sans JP（SIL Open Font License 1.1）を使い、端末の書体には頼らない。
- スキャンの見た目（傾き 0.45 度・紙の地の色むら・ノイズ）は CSS と SVG のフィルターで付け、ノイズの種も決めている。
- PDF には文書情報（作成者・作成した道具・日時）を書かない。
- 大きい版は、Chrome の画面を 2 倍の細かさ（deviceScaleFactor 2）で写して 300 dpi（2480 × 3508 ピクセル）にし、JPEG の質を 95 にしている。組み方は 150 dpi の版と同じなので、黒い四角の場所（pt）も同じになる。3,000,000 バイトを超えないときは、作るのを止める。
- 同じパソコンで 2 回作り、7 つのファイルが 1 バイトも違わないことを確かめた（2026-11-05）。Chrome の版や OS が違うと、画像の画素が少し変わることがある（推測）。そのときも、黒い四角の場所は `boxes.json` に出るので、`tests/demo-scan-minutes.test.ts` が食い違いを止める。

## 作品で読み込んだとき（2026-11-05 に確かめた）

`tests/demo-scan-minutes.test.ts`（`npm test`）で、毎回確かめる：

- 字の層・書体がなく、文書情報もない。黒く塗った四角の注釈が 3 つ、`boxes.json` の場所にある
- 今の検出ルールで、見せかけの黒塗り（P6）の画像の層の「高」が 3 件だけ出る（ほかの型は出ない）
- 整えると、黒い四角の下の画像を 3 か所だけ塗る（四角の外は塗らない）。画面の「読み直す」と同じ流れで、残りは 0、緑（clean）
- 大きい版：P6 の「高」が 3 件だけ出て、整えると 0（緑）。整えたあとも 3MB を超え、画面と同じ順（`nextForLimit`）で「3MB 以下」に縮めると、1 回め（ふつう：150 dpi・質 0.75）で上限に収まり、縮めたあとの読み直しも 0

大きさ（2026-11-05 に手元で測った。1MB＝1,000,000 バイト）：

| ファイル | 元 | 整えたあと | ふつう（150 dpi・質 0.75）で縮めたあと | もっと小さく（100 dpi・質 0.6） |
|---|---|---|---|---|
| `scan-minutes-large.pdf` | 6,417,901 | 6,013,954 | 386,433 | 169,029 |
| `scan-minutes-large-synthetic.pdf` | 6,441,010 | 6,036,443 | 392,295 | 171,744 |

画面では、「3MB 以下」を選ぶと「ふつう」で縮めた時点で収まるので、「もっと小さく」は使わない。

## 注意

- 動画・説明で使うときは、架空の資料であることが分かるようにしてください（隅の一言を入れた版がある）。
- 黒い四角の注釈は、枠の線を引かず、塗るだけにしている。線を引くと、四角の外へ半分はみ出した細い帯ができ、整えるときに帯ごとに「済」の印が付いて、画面がにぎやかになるため。
