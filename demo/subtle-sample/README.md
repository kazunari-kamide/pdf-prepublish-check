# 検査のページの「気づきにくい見本」

検査のページの「見本の PDF で試す」には、見本が 2 つあります。

- **基本の見本**：今までの見本（架空の申請書）。中身は変えていません。
- **気づきにくい見本**：ここにある `subtle-sample.pdf`（画面での名前は「見本_審査会資料（架空）.pdf」）。期間中に足した 3 つの型と、見た目では分からないもの 2 つを入れた、架空の 4 ページの書類です。

**中身はすべて架空で、このリポジトリで作ったものです。** 実在の役所・人・住所・番号は使っていません。市の名前（白樺野市）・町の名前（空見台・月影町）・人の名前も架空です（実在しないことは、すべての市区町村・町名・人名と照らしてはいません）。郵便番号・電話番号は 0 を並べただけです。ほかの道具のテスト用 PDF や文言は使っていません。採点に使う `fixtures/` には入れていません。

## 入れたもの

| ページ | 形 | 当たるルール | 整えたあと |
|---|---|---|---|
| 1（スキャン） | 通知書。宛先を黒く塗ったが、すぐ上の郵便のバーコードのような記号（架空の並び 60 本。意味のある値は表していない）は塗られずに残る | `barcode-scan`（黒塗りのそばの記号。#182） | 残る（記号を塗るかは人が決める） |
| 2・3（スキャン） | 同じ書式の申請書 2 枚。2 ページ目は氏名と電話番号を塗ったが、3 ページ目は電話番号だけを塗り、氏名を塗り忘れた | `cross-page-redaction`（同じ書式のページの塗り残し。#193） | 残る（塗り忘れは元の書類で直す） |
| 4（字の層あり） | 会議録。候補地の地名の上に黒い四角を重ねただけで、下に字が残る。同じ地名が、下の段落に塗られずに出る | `p6-text`（見せかけの黒塗り）と `redacted-text-elsewhere`（塗った字が、ほかの所に出ている。#195） | 四角の下の字は消える。ほかの所の同じ字は残る |
| ファイル全体 | 文書情報の作成者に人の名前。前の版の文書情報（題が「下書き」のもの）が、ファイルの中に残る（増分の更新） | `p1-info`（文書情報）と `p5-revisions`（旧版の残存） | 消える |

整えると 7 か所が 3 か所になり、残った 3 か所は「整える」では消せない残り方です。画面では、そのとき「なぜ残ったか・どこか・元の書類で直すこと」の 1 文を出し、保存を止めます（`src/ui/model.ts` の `FIX_IN_SOURCE_WHY`）。

## 作り直し方

```
node demo/subtle-sample/build.mjs
```

- スキャンのページは、`@napi-rs/canvas` で字を画素に描き、灰色・Flate の画像（144dpi）にします。外の道具・通信は使いません。
- 書体は `design/fonts/source/` の Noto Sans JP（SIL Open Font License 1.1）です。4 ページ目は、`subset-font` で使う字だけ・太さ 400 の固定の書体にしてから埋め込みます（pdf-lib の切り出しでは、可変の書体の字が欠けて描かれたため）。
- 作り直すと 1 バイトも違わないことを、`tests/demo-subtle-sample.test.ts` が確かめます。
- 画面に頭の 2 字が出る値（作成者・地名）は、最初の画面で読み終えている書体の字だけにしています。読んでいない切れ端の字だと、PDF を入れたあとに同じサイトへ書体を取りに行き、`npm run check:browser` の「PDF を入れた後の要求 0 件」に反するためです。

## 確かめていること（`tests/demo-subtle-sample.test.ts`）

- 本番と同じ検査（`RULES`・画像の解き手あり）で、上の表の 7 か所だけが出て、ほかの型は出ない。
- 整えて読み直すと（画面の Worker と同じく、塗った下の字を覚えて渡す）、`barcode-scan`・`cross-page-redaction`・`redacted-text-elsewhere` の 3 か所だけが残り、保存は止まる。そのとき、上の説明の文が出る。
