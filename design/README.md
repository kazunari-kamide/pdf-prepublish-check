## 画面の組み立て

```
┌──────────────────────────────────────────────────────────────────┐
│ [袋]お守りPDF                                        お守りPDF について │ ← 軽い帯
├──────────────────────────────────────────────────────────────────┤
│ 公開する前の PDF に、消したつもりの情報が残っていないか確かめます（選ぶ前だけ）│ ← 紹介の 1 行
│ (✓選ぶ)(✓確かめる)(3 整える 「整える」を押します)(4 読み直す 通れば保存…)  │ ← 進み具合
├──────┬────────────────────────────┬─────────────────────────────┤
│ 縮小 │                            │ 種類ごとの結果                │
│ した │   大きなページ               │ ┌──┬──────────────────┐    │
│ 各   │   ┌──┐ ← 番号つきの枠        │ │黒│見せかけの黒塗り(P6) 1件│    │
│ページ│   └──┘                     │ │塗│ [1 ▲高 ページ2 …]  │    │
│      │                            │ │り│                    │    │
│      │                            │ └──┴──────────────────┘    │
│      │                            │ ┌──┬ 見つからなかった種類 ┐    │
│      │                            │ │済│ ✓ 見つかりませんでした│    │
└──────┴────────────────────────────┴─────────────────────────────┘
```

- **上：軽い帯**。ロゴと「お守りPDF について」（/about）だけ（2026-11-05 本人の画面のレビュー 1-1）。
- **その下、左右 2 列の上：紹介の 1 行と進み具合**（1-1・1-2）。紹介の 1 行は選ぶ前だけ出し、PDF を置いたら隠す。進み具合は 4 段を丸い札で並べ、置いたあとも残す。いまの段は墨の地に白の字（`aria-current="step"` でも伝える）。済んだ段は番号の丸を緑の ✓ にする。説明の一言は、いまの段にだけ出す（A4）。ほかの段は名前だけにし、説明は読み上げにだけ残す。ただし「④ 通れば保存できます」は、まだのうちも出す。
- **選ぶ前**（A1・A3・A5・A6）：右の結果の欄も、灰色の台も出さない。置き場を主役にし、枠全体を押せるようにする。ブラウザの「ファイルを選択／選択されていません」は見せず（欄は残して Tab で届く）、見た目のボタンは「PDF を選ぶ」1 つにする。枠のすぐ下に、文字のリンクくらいの目立たせ方の入口を 2 つ置く（「見本の PDF で試す（架空の申請書）」、開けて選ぶ「提出先の容量に合わせて小さくしたいとき」）。その下に、利用規約の 1 行を小さな字で置く。
- **送らないことの一文**は、ファイルを渡す置き場の中の 1 か所だけに出す（A2）。印は「✓」（「○」は、選んでいないラジオボタンに見えるため。A7）。画面が数えた値ではないので「送信 0 件」とは言い切らない（2026-11-04 本人が決めた）。
- **左：縮小した各ページ**。見つかった所のあるページには、紅の丸い札で数を出す。
- **真ん中：大きなページ**。PDF.js で描いたページの絵の上に、番号つきの枠を重ねる。台は角を丸めた薄い灰。
- **右：種類ごとの結果**。いちばん上に結論を1文で出す（3つに分ける：見つかった／調べた範囲では見つからなかった／調べきれなかった所がある）。見つかった種類ごとに角を丸めた囲みを作り、左に紅の細い帯を立てる（字は出さない。2026-11-05 本人の画面のレビュー B4。前は縦書きの札「黒塗り」「文書情報」など）。項目を押すと、そのページに移り、枠を目立たせる。
- 結果の並び（2026-11-05 本人の画面のレビュー B1・B2・B8）：結論 → 「整える」 → 1 行の説明 → 開けて読む「整えると消すもの」 → 中身を伏せていることの一言（1 回だけ） → 種類ごとの囲み → 「自分で黒塗りする所を選ぶ」 → 「見つけられるのは、ここに並べた種類だけ」の知らせ → 見た所・見なかった所。
- 整えた結果（C1〜C3）：前後の数の 1 行 → 保存のボタンと一言 → 消せなかった所（あるときだけ）→ 開けて読む「くわしい内容」（種類ごとの数・見つかった種類で消したもの・念のため消したもの・プロパティ）と「そのほかの操作（報告書・小さくする）」。見つかった数と消した数を 1 つの合計にしない。
- 縮小したページの列は、2 ページ以上のときだけ出す（B6）。PDF の欄は中身の高さで止め、幅の広い画面では、結果をスクロールしてもページが見えるよう上に貼り付ける（D1）。
- その下に、毎回「**見た所・見なかった所**」の囲み（札「範囲」）を出す。P1〜P12 と新しい型（個人情報・お知らせ）を1行ずつ、「調べた／一部だけ調べた／調べられなかった／この版では調べていない」で並べ、理由も書く（2026-11-05。前の「済」「未」の囲みは、これにまとめた）。「安全です」「問題なし」とは書かない。
- 本文へ飛ぶリンク「結果へ移る」を、キーボードで最初に止まる所に置く（ふだんは見えない）。
- 幅が狭いとき（html の字で 50rem 未満。字が 18px のとき 900px。`@container page` で測るので、字を大きくすると早めに切り替わる）は、帯 → 紹介の 1 行と進み具合（2列×2段）→ 結果 → 縮小（横に並べて折り返す）→ ページの順に縦に並べる。選ぶ前は、紹介・進み具合・置き場がスクロールせずに入るように詰める（幅 390px では置き場の全体、320×568 では置き場の題と「PDF を選ぶ」まで）。左の色の帯は、囲みの上の細い横の帯に変える。幅 320px でも横にはみ出さない。

## 文字

- 見出しも本文もゴシック。見出しは太字で分ける。本文は `112.5%`（ブラウザの既定 16px のとき 18px。大きめ。DADS の基準 16px 以上を満たす）。px で決め打ちせず、ブラウザの字の大きさの設定に従う（2026-11-05）。ほかの字・余白・欄の幅は rem で、本文の字と一緒に大きくなる。押せる所の大きさ（44px）・線の太さは px のまま。字の間は 0.02em（DADS：26px 以下の字は 2%）。
- 書体は、同梱の **Noto Sans JP**（SIL OFL 1.1）。Shift_JIS の字と画面の記号だけ、太さ 400〜700 に絞った WOFF2 を、自分のサイトから読む（外から読み込まない。CLAUDE.md §2-1）。2026-11-05 本人が承認。作り方・ライセンスの守り方は `design/fonts/README.md`。ない字と、読み終わるまでの間は、端末の書体（BIZ UDPゴシックなど）で出す。
- 結果の欄のいちばん下に、書体の名前・著作権・ライセンスの文へのリンクを小さく出す（`.font-note`）。

## 押せる所とフォーカス

- 押せる所は、高さ 44px 以上（`--target-min`）。大きなボタン（整える・保存する）は 56px（`--button-height-large`）。DADS のボタンの「ターゲット領域は 44 CSS px 以上」にそろえた。
- フォーカスは、どの押せる所・入力欄でも同じ形：**墨 `#2B2A28` の 1 色**の 3px の線を、外側に 3px 離して出す（`design/sheet.css` の `--focus-ring`・`--bw-focus`・`--focus-gap`。サイトのページ〔持ち場 D〕と同じ値）。墨のボタンでは、線とボタンの間に周りの地のすき間を挟んで見分ける。2026-11-05 本人「2 重で出てくるのが好きでない。1 色でいい」で、黄と黒の 2 重をやめた。線は周りの地の上に載るので、白 14.34・画面の下地 13.74・薄い墨の台 12.16・札の地 12.82・薄い紅 12.14・薄い緑 12.35（2026-11-05 計算）のどれでも 3:1 以上（WCAG 1.4.11）。「結果へ移る」も、黄の地をやめて墨の地に白の字にした。
- 字を打つ欄（`input`・`textarea`・`select`。チェックボックス・ラジオボタンは除く）は、角を `--radius-m`（8px）で丸める。
- 影は1段だけ（`--shadow-panel`・`--shadow-sheet`）。重ねない。

## 危ない所の示し方

色だけで示さない（CLAUDE.md §6）。

- ページの上：紅の太い枠＋丸い番号の札（枠の左上の外）。
- 一覧：番号・「▲ 高」「■ 中」「● 低」の丸い札（形と文字）・ページ番号。
- 種類の札：囲みの左の細い色の帯だけ（字は出さない。見出しと同じことを 2 回言わないため。2026-11-05 本人の画面のレビュー B4）。幅が狭いときは、囲みの上の細い横の帯。見出しは種類の名前だけにし、P の番号は項目を開いたときの細かい所に出す（B3）。短い名前の表 `src/ui/fuda.ts` は、ほかの所で使うために残す。
- 選んだ項目：線を太く紅に。ページの上の枠を太くし、札を白抜きにする（形も変わる）。
- 消した所：緑の**点線**の細い枠＋「済」の札（字でも示す）。押せない。
- 確かめてほしい所（ルールが言い切れないとした所。P6 の confidence: check・画像を解けなかった所）：深刻度の札の代わりに点線の「？ 確かめる」の札。項目の枠も点線。題は「残っているかもしれません」と断定しない。
- 見た所・見なかった所：「✓ 調べた：見つからない」（緑）、「▲ 調べた：見つかった N 件」（紅）、「◐ 一部だけ調べた」、「－ 調べられなかった」・「○ この版では調べていない」（補足の色）。印と字で示す。
- 消せなかった所：「▲ 消せなかった所」の見出しと、紅の左の線（字と形でも示す）。
- 見えている個人情報らしい字（黒塗りの候補。P13【仮】）：見えない情報とは別に数え、紅にしない（2026-11-05 夜のレビュー §0）。種類の囲みは墨の帯と見出しの前の「ｉ」、番号の丸は点線、ページの上の枠は墨の点線と墨の札。見出しの数・手順の帯・整える前後の数には入れず、別の一文「ほかに、見えている個人情報らしい字が N か所あります（黒塗りするかは、あなたが決めます）」と、整えた結果の 2 行目「見えている個人情報らしい字：N か所 → M か所」で出す。番号は、一覧に並べた順（見えない情報の種類を重い順 → 候補の種類）に上から振る。

## アクセシビリティで確かめたこと

ISO/IEC 40500:2012 と JIS X 8341-3:2016 は WCAG 2.0 と同じ内容。DADS は WCAG 2.2 も並べて示しているので、**WCAG 2.2 の AA を目標にしている**。下は確かめた項目だけで、「準拠」とは言わない。

| 項目 | 確かめ方（2026-11-05） | 結果 |
|---|---|---|
| 1.4.3・1.4.11 コントラスト | 計算（上の表） | 基準を満たす |
| 1.4.10 リフロー | 合成 PDF 8 件を、幅 420px（整えたあとも）と 320px で開き、横の長さを測った | 横にはみ出さない |
| 2.4.1 ブロックスキップ | Tab を1回押して撮った | 「結果へ移る」が出る |
| 2.4.7 フォーカスが見える | Tab で項目に移って撮った | 墨の 1 色の線が、外側に離れて出る（2026-11-05 に 1 色へ変えたあと、「見本の PDF で試す」で目で見た。それまでは黒の線と黄の縁） |
| 2.5.8 押せる所の大きさ | CSS の値 | 44px 以上 |
| 2.1.1 キーボード（2026-11-05 夜） | Chrome をキーボードの操作だけで動かし、見本 → 整える → 保存、自分で黒塗りする所を選ぶ、小さくする、まで進めた | 進めた。ページの絵の上で選ぶのは、Enter・矢印・Shift＋矢印・Esc でもできる |
| 2.4.3 フォーカスの順・3.2 動きの予測 | 同上。押したボタンが隠れたとき・整えたあと・小さくしたあとの、フォーカスの行き先を読んだ | 結果の見出し・整えた結果の見出し・小さくする欄の見出しへ移る |
| 1.4.10 リフロー・1.4.4 200% の拡大 | 幅 320・360・420・640（1280 の画面を 200% にした幅の代わり）で、最初・結果・整えたあと・小さくしたあとの横の長さを測った | 横にはみ出さない |
| 4.1.2 名前・役割 | Chrome のアクセシビリティの木（読み上げの道具が使う名前と役割）を読んだ | 名前のない押せる所は 0 個。見出しに型の名前と数、状態の文は `role="status"` |

まだ確かめていないこと：実際のスクリーンリーダー（NVDA・VoiceOver など）での読み上げ、ブラウザの文字だけの拡大、ハイコントラストの設定、自動の検査の道具。
