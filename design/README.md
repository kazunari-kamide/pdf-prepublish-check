# デザインの決まり

色・文字・余白・部品の決まり。値は `design/tokens.css` に CSS の変数として置き、画面（`src/style.css`）はその変数だけを使う。決まりにない部品や値を足すときは、先にここと `tokens.css` に足してから使う（CLAUDE.md §6）。

画面の案 A・B・C（`src/design-proposals/`、選ばなかった部分も残す）から、2026-11-03 に本人の返事（PR #31）で次の組み合わせに決めた。

## 画面の組み立て

```
┌─────────────────────────────────────────────────────────────┐
│ お守りPDF   1 選ぶ │ 2 確かめる │ 3 片付ける │ 4 読み直す   送信 0 件… │ ← 手順の帯（案 C）
├──────┬──────────────────────────────┬──────────────────────┤
│ 縮小 │                              │ 種類ごとの結果（案 C）│
│ した │   大きなページ（案 B）         │  見せかけの黒塗り 1件 │
│ 各   │   ┌──┐ ← 番号つきの枠          │   1 ▲高 ページ2 …    │
│ ページ│   └──┘                       │  隠れたテキスト       │
│（案 B）│                              │   見つかりませんでした │
└──────┴──────────────────────────────┴──────────────────────┘
```

- **上：手順の帯**（案 C）。いまの段に墨の地を敷く。「送信 0 件・このパソコンの中だけで確かめています」を帯の右に常に出す（案 B）。
- **左：縮小した各ページ**（案 B）。見つかった所のあるページには、紅の札で数を出す。
- **真ん中：大きなページ**（案 B）。PDF.js で描いたページの絵の上に、番号つきの枠を重ねる。
- **右：種類ごとの結果**（案 C）。型ごとにまとめ、見つからなかった型も「見つかりませんでした」と出す。項目を押すと、そのページに移り、枠を目立たせる。
- 幅が狭いとき（56rem 未満）は、帯（手順は2列×2段）→ 結果 → 縮小（横に並べる）→ ページの順に縦に並べる。

## 色

| 役 | 変数 | 値 | 使う所 |
|---|---|---|---|
| ベース | `--color-base` | `#2B2A28` 墨 | 文字・線・手順の帯 |
| アクセント | `--color-accent` | `#A3201B` 紅 | 危ない所の枠・番号の札・件数 |
| 状態の色 | `--color-ok` | `#2F6F5E` 緑 | 見つからなかった型・片付いた所（「全部緑」）。2色の決まりの外に置く（2026-11-03 本人が承認） |

下地の色（`--color-paper` など）は、ベース色を薄めたもの。

## 文字

- 見出しは明朝、本文はゴシック。本文は 18px（大きめ）。
- 書体はいまは端末に入っているものを使う。同梱する書体は決めてから、ライセンスを確かめて `docs/licenses.md` に足す（外から読み込まない。CLAUDE.md §2-1）。

## 危ない所の示し方

色だけで示さない（CLAUDE.md §6）。

- ページの上：紅の太い枠＋番号の札（枠の左上の外）。
- 一覧：番号・「▲ 高」「■ 中」「● 低」の形と文字・ページ番号。
- 選んだ項目：枠を太くし、ページの上の札を白抜きにする（形も変わる）。

## 部品の一覧

| 部品 | クラス | 決まり |
|---|---|---|
| 手順の帯 | `.steps` | 4段。いまの段は墨の地に白の字。済んだ段は「済」の字をつける |
| 送信 0 件の札 | `.zero-send` | 帯の右。白の線で囲む |
| 縮小したページ | `.thumb` | 幅 `--width-thumbs` の中。見つかった数の札 `.thumb-count` |
| 大きなページ | `.sheet` | 絵（canvas）の上に枠（`.mark`）を重ねる |
| 枠 | `.mark` | `--border-mark` の紅。番号の札 `.mark-no`。選んだ枠は `.is-selected` |
| 種類ごとの結果 | `.group` | 見出しに型の名前と件数。見つからなければ緑の字で「見つかりませんでした」 |
| 項目 | `.item` | 押せる（button）。番号・深刻度・ページ・何が残っているか・なぜ危ないか |
| お知らせ | `.notice` | 左に墨の線。省いたページ・調べなかった画像など |
| 全部緑 | `.verified[data-state="clean"]` | 緑の枠。「調べた項目では、見つかりませんでした」 |
