# ロゴマーク

お守りPDF のロゴマーク。2026-11-05 に、案 AX2 に決めた（いきさつは [design/proposals/2026-11-05-logo/](../proposals/2026-11-05-logo/README.md)）。

## 使える条件（ライセンス）

**このフォルダの SVG（`*.svg`）は、AGPL-3.0-only ではありません。** SPDX の識別子は `LicenseRef-OmamoriPDF-Logo` です。

- 著作権は作者が持ちます。
- 公式の「お守りPDF」（`https://omamoripdf.com/`）と、このリポジトリを手を加えずに配るときは、そのまま使えます。
- **改変版（コードに手を加えたもの）には使えません。** 改変して公開するときは、ロゴを外し、別の名前にしてください（README の「ライセンスと名前」）。
- 「お守りPDF」を紹介する記事や資料で、公式のものを指すために使うのは構いません。形・色を変えないでください。

ロゴを差し込むコード（`logo.ts`）と、この README は AGPL-3.0-only です。

## 形の意味

- **紅の袋**：お守り袋。上の角を斜めに切って、本物のお守り袋の形に近づけた。
- **紐の結び目**：両側に輪のある結び目（墨）。
- **線だけの紙と、行2本**：袋の中に、守られている書類がある。黒い帯にはしない（墨消しは、見つける型の一つにすぎないため）。

## ファイルと使い分け

| ファイル | 使う所 | 大きさ |
|---|---|---|
| `mark.svg` | 明るい地（手順の帯の見出しなど） | 40px 以上 |
| `mark-on-dark.svg` | 墨の地（サイトのページの帯など）。紐と結び目を `#FBFAF7` にする | 40px 以上 |
| `mark-small.svg` | 40px 未満と、ファビコン。紙を白く塗りつぶし、行を省き、紐を太くする | 40px 未満 |

- 画面へは `logo.ts` が差し込む。見出しのマークは HTML の中に SVG を直接書き込み、ファビコンは `data:` の形にする（どちらも通信を増やさない。CLAUDE.md §2-1）。
- SVG は `fill=` などの属性だけで書く。`style`・`<style>`・`<script>`・リンクは入れない（CSP の `style-src 'self'` で止まるため。`logo.ts` が見つけたら止める）。
- 色は `design/tokens.css` にある値だけ（墨 `#2B2A28`・紅 `#A3201B`・白 `#FFFFFF`・下地 `#FBFAF7`・折り角 `#D69B98`）。`tests/logo.test.ts` で確かめる。

## 余白と並べ方

- マークの周りには、マークの幅の 1/8 以上の余白をとる（64px のマークなら 8px）。
- 名前（「お守りPDF」）と並べるときは、マークを左、名前を右にし、間を `--space-2` にする。名前の字は本文の書体の太字。

## してはいけないこと

- 縦や横だけに伸ばす・回す・傾ける。
- 色を変える。グラデーション・影・縁取りを足す。
- 紅の地や写真の上に置く（袋の紅が埋もれる）。墨の地では `mark-on-dark.svg` を使う。
- 40px 未満で `mark.svg` を使う（紙の線がかすれる）。
