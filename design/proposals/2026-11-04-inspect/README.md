# 検査の画面の見た目の案（2026-11-04、選ぶ前の見本）

**この3案は選ばれず、第2版（`../2026-11-05-inspect-v2/`）の E2 に決まった。** 選ばなかった案として残す。

この3案は `design/tokens.css` を読み込むので、2026-11-05 に決まりを変えたあとは、ブラウザで開くと見出しの書体や角の丸めが当時と変わって見える。当時の見た目は `screenshots/` の画像で見る。

検査の画面（「2 確かめる」の段）の見た目の案を3つ並べる。どれも**動かない見本**で、項目と数字は架空のもの（実在の PDF・団体・人は出てこない）。選ぶのは本人。**選ばなかった案も、ここに残す。**

- 組み立て（上に手順の帯、左に縮小したページ、真ん中に大きなページ、右に種類ごとの結果）は `design/README.md` の決まりのまま。変えたのは見た目の方向だけ。
- 色・文字・余白は `design/tokens.css` の変数だけを使った（`../../tokens.css` を読み込む）。決まりにない値は、右の欄の幅（D・E の 30rem、F の 19rem）と、F の説明の位置だけ。選んだら、先に `tokens.css` に足してから画面に当てる（CLAUDE.md §6）。
- 危ない所は、どの案も色だけで示さない（紅の枠・番号の札・「▲ 高」「■ 中」の形と文字・ページ番号）。
- ブラウザでファイルを直接開いて見る。ビルドには入らない。画像は `screenshots/`（幅 1440 × 高さ 900 で撮った）。
- `/design` はこのときのセッションで使えなかったので、Claude Code で直接作った（CLAUDE.md §6 の「使えなければ」）。
