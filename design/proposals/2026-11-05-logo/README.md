# ロゴの案（2026-11-05）

ロゴマークの案と、選んだいきさつ。選ばなかった案も [candidates.svg](candidates.svg) に1枚で残す（案の図は、ロゴと同じ条件。[design/logo/README.md](../../logo/README.md)）。

## 選んだ案

**AX2 行2本**（A3 の紐 × A2 の中身）。本人が決めた（2026-11-05）。決まったロゴは `design/logo/`。

## いきさつ

1. 最初の5案：A 袋と紙、B 札と確かめ印、C 黒塗りの下を見る、D 紋（丸に紙）、E 朱印と折り角。本人が A と B を残した。色（墨・紅）はそのままでよい、中身をもっと洗練させたい、という返事。
2. A・B の展開を3つずつ：A1 窓のある袋、A2 白抜きの紙、A3 縦の名札と結び／B1 墨の札、B2 黒塗りと丸印、B3 朱の頭。本人が「紐は A3、中身は A1 か A2」とした。
3. 中身は A2 にした。墨消しは、見つける型（P1〜P12）の一つにすぎないので、黒い帯（A1）で道具の意味を狭めない。線だけの紙なら「書類を守る」とだけ読める。
4. A3 の紐 × A2 の中身で、紙の行を 1本（AX1）・2本（AX2）・なし（AX3）の3つを作り、AX2 にした。2本だと文章の行と読め、黒塗りの帯に見えにくい。
5. A2 の白い線は、16px では約 0.7px になり、かすれるおそれがある（画面で確かめる前の推測）。そのため、線を 2.8 から 3.4 に太くし、40px 未満では、紙を塗りつぶして行を省いた「小さいとき用の形」を使う。

## 選ばなかった理由（短く）

| 案 | 理由 |
|---|---|
| A・A1 | 白い紙に黒い帯で、黒塗りの道具だと読まれやすい |
| A3 の中身（縦の名札） | 縦書きの字が小さいとつぶれる。紐の形だけ使った |
| B・B1〜B3 | 札は「確かめた」は伝わるが、名前の「お守り」とのつながりが袋より弱い |
| C | 部品が多く、16px でいちばん苦しい。黒塗りに寄りすぎる |
| D | 落ち着いているが、お守りらしさが弱い |
| E | 「守」の字を書体で描くので、本番では図形に直す手間がある。形がよくある印に近い |
| AX1・AX3 | 1本は黒い帯にも見える。なしは紙だけで、書類らしさが少し弱い |

案はデザインのキャンバス（Claude の Artifact。非公開）で並べて比べた。キャンバスの元のファイルは、Google Fonts を読む行を含むので、リポジトリには入れていない。
