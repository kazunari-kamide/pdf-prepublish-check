- 実在の個人名・団体名は書きません。実データでの採点は件数だけを書きます。
- 数字は測ったものだけを書きます。

### 2026-11-03 の採点の内訳（`npm run eval`、合成 PDF 26 個）

- 判定：**不合格**（検出率が基準の 95% に届かない。片付けたあとに残る情報は、片付けの機能がまだないので未測定）。画像の層・注釈の型での不合格は、意図したもの（rubric/p6.md §1）。
- 検証器そのものの確かめ（`verifier/selfcheck.mjs`）：合格。

| 型（層 / 覆っているもの） | 漏れ | 見つけた |
|---|---|---|
| text/fill | 12 | 12 |
| text/image | 1 | 0 |
| text/annotation | 2 | 0 |
| image/fill | 5 | 0 |
| image/image | 1 | 0 |
| image/annotation | 2 | 0 |

- 誤検知：0 件（漏れでないものに重なった報告 0 件、正解のどれにも重ならなかった報告 0 件）。
- 見つけた 12 件は、覆われた字の数も、すべて正解データと同じだった（合否には使わない）。
- 判定の値は、合成 PDF で漏れと漏れでないものの値を測り、その間に置いた（明るさ：漏れ 0.000〜0.102、薄いマーカー 0.870〜0.886 → 0.35。字が隠れる割合：漏れ 1.000、下線など 0.078〜0.125 → 0.5）。詳しくは `rules/p6-text/README.md`。
- 同じ採点を3回回し、結果は同じだった。1回にかかった時間は約 1 秒（Node の起動を含む）。
