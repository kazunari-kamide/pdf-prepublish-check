### 2026-11-04 の片付けの直し：`sanitize` 0.3.1（覆いの箱）

- **報告の箱**：画像の画素を塗ったとき、`removed` の `covered_pixels` の `rect` を、覆いごとの「覆いの箱と画像の箱の重なり」（ページの座標）にした。これまでは、その画像の上の覆いを全部まとめた1つの箱だった。`count` は、その覆いで塗った画素の数（2つの覆いに入る画素は、先に描いた覆いで数える）。
- **合成 PDF（P6）で比べた値**：画像を塗った PDF 7 個で、`covered_pixels` は 7 件 → 14 件。塗った画素の合計は 143187 → 143187 で同じ。箱の面積の合計は 413211 → 91830（平方ポイント）。変わったのは、覆いが複数ある 3 個（i03・i05・n02）。i03 は覆いの箱が重なっているため、面積の合計が 3591 → 3610 と少し増えた。ほかの項目（消した字・片付けられなかった所など）が変わった PDF は 0 個。
- **`npm run eval`**：片付けたあとに残る情報は P6・P1・P9・P5・P7 とも 0 件のまま。検出率・誤検知率も 0.3.0 のときと同じ。
- **`npm run check:sanitized`**：5つの型で 0.3.0 と同じ（問題ありは P6 の i03・i05 の 2 個、見た目の差の合計 2579 画素。ほかの型は 0 画素）。
- **テスト**：1つの画像に覆いが2つある場合のテストを足し、前からある1つの覆いのテストに、箱が塗った所になることの確かめを足した。`npx vitest run` 22 ファイル 367 件が通った。
- **限界の1行**：注釈の見た目（`/AP`）の中の `/ActualText` は外していないことを、`sanitize/README.md` に書いた（PR #37 の返事）。
