# 偽のサイトの見分け方と知らせ方

お守りPDF はソースを公開しているので（AGPL-3.0-only）、写したサイトが作られること自体は防げません（ライセンスの上では許されています）。ここでの狙いは次の3つです（CLAUDE.md §11-6）。

1. 本物を見分けやすくする
2. 偽物に早く気づく
3. 悪意のある偽物（PDF を外に送るなど）を止める

## 公式のサイト

- **公式の URL は `https://omamoripdf.com/` だけです。** `www` つきや `http` で開くと、この場所へ送り直します。
- README の冒頭、どのページの下の帯、利用規約にも、同じことを書いています。
- 「お守りPDF」の名前とロゴは、改変版には使えません（README の「ライセンスと名前」）。

## 見分け方（使う人向け）

- アドレスバーの場所が、`omamoripdf.com` ちょうどか（`omamori-pdf.com`・`omamoripdf.co`・`omamoripdf.com.example` などの似た名前ではないか）。
- 公式のドメインで動いていないときに「これは公式のサイトではありません」と出す表示は、まだ作っていません（CLAUDE.md §11-6。作っても、写した人が消せるので、守りの中心にはしない）。
- 本物は、ページを開いたあとも、PDF を入れたあとも、外へ通信しません。ブラウザの開発者ツールの「ネットワーク」で、`omamoripdf.com` 以外への要求がないかを確かめられます。
- 本物は、ログイン・登録・支払いを求めません。

## 偽物の見つけ方（運営する側）

- 検索エンジンで「お守りPDF」と、似た名前を定期的に調べる。
- Search Console で、公式のサイトへのリンク元に、知らない場所がないかを見る。
- サイトのページの canonical は、写されても公式の URL を指したまま残る（`site.ts`）。写したサイトが canonical を消していなければ、検索エンジンは公式のページを本物として扱う（推測）。

## 見つけたときの知らせ方

まず、そのサイトが **悪意のある偽物か**（PDF を外に送る、ログインや支払いを求める、公式を名乗る）を確かめます。ライセンスを守った改変版（別の名前で、ソースを公開している）は、知らせる対象ではありません。

悪意のある偽物なら、次の窓口に知らせます。各窓口の受付の場所（URL）と受け付ける内容は、知らせる時点で、それぞれの公式の案内で確かめてください【本人が確かめる】。

| 窓口 | 何を頼むか |
|---|---|
| 偽のサイトを置いているホスティング先・ドメインの登録先の、不正利用の窓口 | サイトの停止 |
| Google セーフ ブラウジング | ブラウザでの警告の表示 |
| フィッシング対策協議会 | フィッシングのサイトとしての知らせ |
| JPCERT/CC | フィッシングのサイトとしての知らせ・調整 |

- 知らせるのは本人です。Claude は送りません。所属の会社は名乗りません（CLAUDE.md §9）。
- 偽のサイトに、本物の PDF を入れて試さないでください。試すときは、架空の内容で作った PDF を使います。

### 知らせる文のひな形

```
件名：お守りPDF を名乗る偽のサイトについて

【偽のサイトの URL】
【見つけた日時】

お守りPDF（公式のサイト：https://omamoripdf.com/）を運営している者です。
上の URL のサイトが、お守りPDF の名前（とロゴ）を使い、公式のサイトのように見せています。

確かめたこと：
- 【例：PDF を入れると、〇〇 という外の場所へ送る通信が起きる（架空の PDF で確かめた）】
- 【例：ログイン・支払いを求める画面がある】
- 公式のサイトには、これらの機能はありません。

公式のサイトのソースは公開しています：【GitHub のリポジトリの URL】
証拠として、画面の写しと通信の記録を添えます。

【運営者の表示】
```
