# 画面の言葉の見直し（案の一覧）

2026-11-04 作成。**どれにするかは本人が決める。**

2026-11-05（B）：決まりに反している所と、言葉がそろっていない所だけ、案1を画面に入れた（下の表の「済」）。ほかは、まだ変えていない。

2026-11-05（E）：本人が「片付ける」を「整える」に決めた（下の表の 3 の案「消す」「見えない情報を消す」は、整えた中身の内訳の言い方として使う）。あとでプロパティを直す機能も入るので、「消す」に絞らない語にした。画面は B（#88）、`sanitize/` の返す文は C、記事・サイトのページ・`docs/`・README は E がそろえた。下の表は、見直しをした時点の記録なので、「片付ける」のまま残す。
- 「全部 緑になれば完了」「全部 緑になりました」→ 案1（色だけで伝えないため。CLAUDE.md §6）
- 「言い切れない所あり」→ 案1
- 検査の「ほどいて調べました」→「外して調べました」（片付けの文にそろえた）
- 「P6 のうち、画像の下の中身は、読み直しではまだ調べていません」→ 画像の層を調べるようになったので、この文は出さない。読み解けなかった画像があるときだけ「P6 のうち、読み解けなかった画像の下の中身は、調べていません。」と出す

初めて使う人（PDF に詳しくない職員）に伝わりにくい言葉を、画面に出る文から全部拾った。拾った場所は `index.html`、`src/main.ts`、`src/ui/model.ts`、`src/ui/clean-model.ts`、`src/ui/scope.ts`、`src/inspect/rules.ts`、それと片付けが返す文（`sanitize/`）。

- 案は2つまで。どの案も、`docs/glossary.md` の「使わない言い方」に当たらないものにした。
- 決まった言葉は `docs/glossary.md` に足してから画面に入れる（glossary の決まり）。
- 片付けが返す文（表の「場所」が `sanitize/` のもの）は、片付けの担当（C）の範囲。決まったら C に頼む。
- 進捗報告の動画では「片付ける」を「消す」、「旧版の残存」を「消したはずの前の版」と言い換えた。案1は、なるべくその言い方にそろえた。

## 6. 言葉がそろっていない所（どれかにそろえたい）

| 同じことを指す言葉 | 出ている所 | そろえる案 |
|---|---|---|
| 片付ける・取り除く・消す・外す | 帯、ボタン、片付けた結果、片付けが返す文 | 画面では「消す」に寄せる。注釈・添付・JavaScript のように丸ごと抜くものも「消す」でよいか |
| ほどいて（暗号化） / 外して | 検査のお知らせ / 片付けたあとのお知らせ | 「外して」 |
| 層 / レイヤー | 検査（P7） / 片付け | 「表示を切ってある部分」 |
| 背景 / 地 | 検査（P7） / 片付け | 「背景」 |
| 確かめる・調べる・検査・読み直す | 帯、お知らせ、片付けた結果 | 「調べる」に寄せ、2回目は「もう一度調べる」 |
| 見つかった所・か所・件 | 帯、見出し、件数 | ページの上にあるものは「か所」、型ごとの数は「件」でよいか |
