# PDF 以外の形式（formats/）

写真と今の Office のファイルに残った、見た目では分からない情報を**知らせる**部品です。消す機能・画面に出す機能は、まだありません（入口の関数とコマンドの道具まで）。

- 入口：`inspectFormat(bytes)`（`formats/index.ts`）。形式は拡張子ではなく先頭のバイトで見分けます。
- Node の API を使わないので、画面からも、コマンドの道具（`cli/`）からも呼べます。ZIP の展開は、ブラウザと Node にある `DecompressionStream` を使います（依存のライブラリは足していません）。
- 返すのは型・数・場所（段落の番号・何枚目のシートのどのセル・何枚目のスライドの左上から何 pt）だけです。字の中身・欄の値・中のファイル名・シートの名前は返しません。型の一覧は `docs/glossary.md` の「PDF 以外の形式の型」。
- 通信しません（`tests/cli-no-network.test.ts`）。

## 調べること

| 形式 | 調べること |
|---|---|
| JPEG・PNG・WebP | EXIF（撮った場所・撮った人やカメラの番号・説明・機種と日時）、EXIF の中の縮小画像（本体と縦横の比が違えば「切り取る前の写真かもしれない」）、XMP（作成者・編集の履歴・位置）、IPTC（JPEG）、PNG の文字の欄（16 進で書いた EXIF も） |
| HEIC・HEIF | EXIF・XMP の項目が**有るか**だけ。中身は調べず、「調べられなかった所」として知らせる |
| docx | プロパティ（作成者・最後に保存した人・会社名・独自）、ひな形の場所、外へのつながり、埋め込み（中の Office は1段だけ中まで）、中の写真、コメント、変更履歴、隠し文字（字に直接・文字と段落のスタイル）、字と同じ色の蛍光ペン・網掛け、白い字、本文の上の濃い図形 |
| xlsx | プロパティ、外のブック、埋め込み、中の写真、コメント（古い形のメモとスレッド）、隠したシート（再表示できない形も）・行・列、字と同じ色の塗り、白い字、`;;;` の書式、共有ブックの変更履歴 |
| pptx | プロパティ、埋め込み、中の写真、コメント、表示しないスライド、発表者のメモ、字のある図形の上に重ねた濃い図形、字と同じ色の図形、スライドの外の字 |

## 調べていないこと（「残っていない」とは言えない所）

- 古い Office（.doc・.xls・.ppt）・一太郎・パスワードのかかった Office（どれも中が別の入れ物の形）。ファイルを直接渡すと「調べていない」と知らせます。フォルダからは拾いません。
- ZIP64（とても大きな ZIP）、暗号化した ZIP の部分、知らない圧縮。
- PowerPoint のグループにした図形の中（座標の直しが要るため）。グループがあれば「調べられなかった所」として知らせます。
- Word の図形と本文の字の重なり（Word は字の位置を持たないため）。濃い図形があること・段落の番号だけを知らせます。
- Excel の図形の重なり、条件付き書式・テーマの色の明るさを変えたもの（tint）での同じ色。
- グラフの中のデータ、マクロ、フォームの値、Word の文書変数、Excel の名前の定義の隠し、XML の中の独自の部分（customXml）。
- 写真の MPF（複数の画像を入れる形）、写真の絵そのもの（塗りつぶしの下など）。

## 上限

細工されたファイルの前提で、上限を設けています（どれも【仮の値】）。超えた所は「調べられなかった所」として知らせます。

| 何の上限 | 値 | 置き場所 |
|---|---|---|
| ファイルの大きさ | 200MB | `index.ts` の `MAX_FORMAT_BYTES` |
| ZIP の中のファイルの数 | 2 万 | `zip.ts` の `ZIP_LIMITS` |
| 1つの部分を解いた大きさ | 64MB | 同じ |
| すべてを解いた大きさの合計 | 512MB | 同じ |
| 中の写真を調べる数 | 200 | `office.ts` の `MAX_IMAGES` |
| EXIF の IFD の数・項目の数 | 16・1,000 | `exif.ts` |

XML の DOCTYPE の実体は広げません（`xml.ts`）。

## テスト

合成のファイルは、テストの中で一から作ります（`tests/helpers/formats-samples.ts`。中身はすべて架空）。隠しのあるものと、何も残っていない対照の両方を `tests/formats-image.test.ts`・`tests/formats-office.test.ts` に置いています。
