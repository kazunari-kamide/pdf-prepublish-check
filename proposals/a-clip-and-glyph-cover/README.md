# 採点する側に足す案：ページの外にはみ出した画像・白い四角の注釈の下の図形

CLAUDE.md §2-3 に従い、採点する側（`rubric/`・`verifier/`・`fixtures/`）に足す案をここに置く。Claude は採点する側を書き換えない。人が中身を見て、移すかを決める。

## 何を足すか

見つける段の3回目で見逃した 2 つの型。検出ルール P7 1.4.0・P6 1.13.0 で見つけるようにした。

| 型 | 検出ルール | 合成 PDF（`eval/cases/`） |
|---|---|---|
| 画像の大部分（7 割ほど）がページの外にはみ出し、見えない所に元の画像が残る | P7 `p7-hidden` 1.4.0：`image_off_page`（見える割合 50% 以下） | `p7-images.ts`：隠しあり 5・対照 3 |
| パスで描いた字（直線だけの道。塗り・線）の上に、白い不透明な四角の注釈（Square）を重ねただけ | P6 `p6-text` 1.13.0：`layer: "vector"`・`check` | `p6-vector.ts`：隠しあり 5・対照 8 |

作り方：`node proposals/a-clip-and-glyph-cover/build.mjs [出力先]`。合成 PDF と、型ごとの鍵（`*.expected.json`）を書き出す。出力先を省くと `out/`（コミットしない）。

## 採点する側で要ること（案）

- **検証器**（`verifier/`）：
  - P6：出力の形（`verifier/schema.json`）の `layer` は `text`・`image` だけで、図形の層がない。足すなら、片付けたあとの PDF をゼロから読み、白い四角の注釈の下に、ページの中身の道が残っているかを数える読み方が要る（検出ルールのコードは import しない）。
  - P7：見えない所に置いた画像（`image_off_page`・`image_clipped`）は、P7 の採点にまだ入っていない（正解データに、この理由の鍵がない）。
- **正解データ**（`fixtures/`）：上の合成 PDF を移すかどうか。移すなら、正解データの形（`fixtures/p6/*.expected.json`・`fixtures/p7/*.expected.json`）に合わせて書き直す。ここの `*.expected.json` は、`eval:new` の鍵の形で、正解データの形ではない。
- **合格基準**（`rubric/`）：図形の層は、いつも `check`（確かめてください）で出す。検出率に入れるか、お知らせ扱いにするかは人が決める。
