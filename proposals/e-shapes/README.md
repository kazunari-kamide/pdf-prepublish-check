# テスト集にない漏れの形の案（12 個）

CLAUDE.md §2-3 に従い、`fixtures/` に足す合成 PDF と正解データの案をここに置く。人が中身を見て、移すかを決める。字はすべて架空。

## どうやって出したか（2026-11-07）

Workflow で 6 体のエージェントを使った。

1. **見つける**（2 体）：`docs/glossary.md` の型の一覧と `fixtures/*/index.md`・`proposals/*/README.md` を読み、構造の側（別の辞書・別の命令）と書類を作る人の作業の側から、候補を 12 個出した。
2. **反証する**（2 体）：候補ごとに「本当に漏れになるか」「今の型・今の案と重なっていないか」「合成 PDF で作れるか」を、`rules/` と `build.mjs` を読んで調べた。**除いた候補は 0 個**だった。直すべき点（対照の取り方・閾値・深刻度を【仮】にすることなど）は、各案の README に入れた。反証が甘かったおそれがあるので、人の目で確かめてほしい。
3. **案にする**（2 体）：残った 12 個を、`build.mjs`（漏れの PDF 1 個と、似ているが漏れでない対照の PDF 1 個と、正解データ）と README にした。
