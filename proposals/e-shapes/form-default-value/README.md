# 採点する側に足す案：欄の値は消したが、既定の値（/DV）に前の記入が残る（P11）

CLAUDE.md §2-3 に従い、合成 PDF と正解データの案をここに置く。Claude は採点する側を書き換えない。人が中身を見て、移すかを決める。

## 何を足すか

| 合成 PDF | 種類 | 中身 |
|---|---|---|
| `e-dv-01-default-value-left` | 漏れ（default_value）2 件 | `/FT /Tx` の欄を 2 つ。`/V` は無く、見た目（`/AP /N`）は空。`/DV` に「北川花子」と「090-0000-0000」。「Clear」のボタン（`/FT /Btn` の押すボタン、`/A << /S /ResetForm >>`）を 1 つ置く |
| `e-dv-02-guide-words-only` | 漏れでない 2 件 | 既定の値が「記入してください」「（例）」のような決まった案内の言葉だけの欄。同じ「Clear」のボタン |

作り方：`node build.mjs [出力先]`。出力先を省くと、このフォルダの `out/` に書く。名前・電話番号は架空。

- 正解データは `fixtures/p6` の形（`leaks`・`negatives`）にそろえ、`kind`・`field` を足した。`fixtures/` に P11 の置き場はまだ無い。

## なぜ漏れか

前の申請者が記入した様式から、値だけを消して流用すると、既定の値に名前や電話番号が残る。日本の様式によくある「入力内容をクリア」のボタン（ResetForm の動作）や、閲覧ソフトのフォームのリセットを押すと、既定の値が欄に入って画面に出る。中身を読んでも取れる。

- ただし、名前や電話番号が `/DV` に残る作り方は、作る側が既定の値として入れたとき（欄の設定の画面で字を入れたときなど。推測）に限られる。

## 今の型との違い

- `rules/p11-forms/index.ts` は、`/V` の無い欄の `/DV` を、わざと数えない（`notCounted.defaultOnly`）。わざと数えない理由は、ルールの README には書かれていない。
- `fixtures/p5` の `p5-07`・`p5-20`、見ないで作るテスト集の T84・T85 は `/V` の値。`eval/cases/p11.ts` には、`/DV`「default」だけの欄を数えない例がある。
- **数えないとした今の決まりを変える案**なので、PR で人の判断を求める。

## 確かめた結果（2026-11-07、Node、このフォルダの build.mjs）

- 2回作って、2つの PDF とも SHA-256 が同じだった（`e-dv-01`：`226d442c4d756d70`、`e-dv-02`：`5a2fa632763302cb`）。

| 合成 PDF | 検出ルール（`node cli/omamori.ts check --format json`） | 検証器（P6・P1・P5・P7・P9） |
|---|---|---|
| e-dv-01（漏れ 2） | **0 件（2 件とも見逃し）**。「Clear」のボタンの ResetForm にも何も出ない | どれも 0 件（P11 の検証器は無い） |
| e-dv-02（対照） | 0 件 | どれも 0 件 |

検出ルールは漏れ 2 件中 0 件。対照は 0 件。P11 の検証器は `verifier/` に無い。

## ルールを作る段への注意（反証役の注意から）

- 数えるのは、`contactLike` の字（名前の呼び方・3けた以上の数字・メールアドレス）を含む `/DV` だけにし、`eval/cases/p11.ts` の「default」の例は数えないままにする。
- 注意：`rules/p11-forms/index.ts` の `contactLike`（65〜68 行目）は、3けた以上の数字・メールアドレス・「内線」「担当」「様」「さん」などを見る。「090-0000-0000」は 3けた以上の数字で当たるが、「北川花子」は当たらない。名前だけの `/DV` を数えるには、`contactLike` に頼らない手がかり（`rules/pii` の名前の見分け方など）が要る。
- `/DV` が `/V` と同じ欄は、今も値として P11 で数えるので、対照ではなく、重ならないことの確かめに使う（この案には入れていない）。

## 捨てた案

- 対照に「`/DV` と `/V` が同じ値の欄」を入れる案。今の P11 が値として数えるので、対照（出てはいけない）にならない。重ならないことの確かめは別に行う。
