# 合格基準：P7（隠れたテキスト）【案】

機械で読む版は `rubric/p7.json`。2つの中身は同じにする。値を決める・変えるのは人だけ（CLAUDE.md §2-3）。

## 1. 合格の条件（案。P6 にならう）

合成 PDF（`fixtures/p7/`）全体で、次の3つを**すべて**満たすこと。

| 条件 | 値 |
|---|---|
| 検出率 | 95% 以上 |
| 誤検知率 | 5% 以下 |
| 片付けたあとに残る情報 | 0 件 |

- 判定は全体の数字で行う。内訳として、見えない理由（reason）ごとの件数を、いつも並べて出す。

## 2. 数え方

- **1件** ＝ 取り出せるのに、画面では見えない字のまとまり。1回の字を描く命令（Tj・TJ など）の中で、同じ理由で続く字を1件にまとめる。
- **見えない理由**（reason）。1字ごとに、上から順に最初に当たったもの1つにする。

| reason | 中身 | 判定の値（案） |
|---|---|---|
| hidden_layer | 表示しないレイヤー（OCG。既定で OFF）の中 | — |
| off_page | ページの見える範囲（CropBox。なければ MediaBox）の外 | 字の箱の 50% 以上が外 |
| clipped | 切り抜き（クリップ）の外 | 字の箱の 50% 以上が外（切り抜きの範囲は箱で近似） |
| invisible | 描き方が見えない（Tr 3・7）、または字が透明 | 不透明さ 0.1 未満 |
| tiny | 字がとても小さい | 字の高さ 1.0 ポイント未満 |
| same_color | 字の色が、下の色（ページの白・先に塗ったもの・画像）とほぼ同じ | 明るさの差 0.1 未満 |
| covered_light | 字のあとに、濃くない不透明な塗りを重ねて隠した（白い四角など） | 不透明さ 0.9 以上・乗算などでない・字の箱の 50% 以上を隠す |

- **数えないもの**
  - **濃い覆いの下の字は P6 で数える**（見せかけの黒塗り）。P7 の検証器は、字のあとに濃い塗り（明るさ 0.3 以下。P6 の検証器と同じ値）を重ねた字を出さず、`excluded.p6` に数だけを出す。
  - **文字認識の層**（描き方 3 の字を、先に描いた画像の上に置いたもの。スキャンした PDF の検索用）は、漏れでない。`excluded.ocr_layer` に数だけを出す。
  - 注釈の中の字は P8 で数える（P7 の検証器は注釈を描かずに読む）。
- **漏れでないもの（誤検知率の分母）**：薄い灰色でも読める字、黒い地の上の白い字、小さいが読める字、ページの中の端の字、表示するレイヤーの字、切り抜きの中の字、半透明・乗算のマーカー、濃い覆いの下の字（P6）、文字認識の層、ふつうの字。
- **検出率** ＝ 見つけた漏れの数 ÷ 正解データの漏れ（`leaks`）の数
- **誤検知率** ＝ 誤検知の数 ÷ 正解データの「漏れでないもの」（`negatives`）の数
  - 誤検知の数 ＝ 漏れでないものに重なった報告の数 ＋ 正解のどれにも重ならなかった報告の数
- **片付けたあとに残る情報** ＝ 片付けたあとの PDF を検証器にかけたときの `items` の数の合計
  - 検証器が「読めない」と返したもの、省いたページ（`skipped_pages`）があるものは、0 件とは数えない（不合格）。

## 3. 照らし合わせ方

報告と正解データを、次の条件で1対1に結ぶ（P6 と同じ形）。

1. 同じページであること
2. 同じ理由（reason）であること。漏れでないもの（negatives）には理由がないので、2 は見ない
3. 箱の重なりが 50% 以上であること。重なり ＝ 2つの箱の重なった面積 ÷ 小さいほうの箱の面積
4. 1つの正解には、重なりがいちばん大きい報告を1つだけ結ぶ

- 字数（chars）は合否には使わない。検証器そのものの確かめでは、一致するかを見る。

## 4. 採点の流れ

P6 と同じ（rubric/p6.md §4）。片付けた PDF を `node verifier/p7-cli.mjs` にかけ、`items` の数を数える。

## 5. 採点用データ（非公開）

ループには読ませない。人が手元で回し、件数だけを記録する。合格ラインは設けない。
