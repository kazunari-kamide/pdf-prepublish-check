# 検証器：P9（添付ファイル）

PDF を1つ入れると、ファイルの中に残っている添付ファイル（埋め込まれた別のファイル）を JSON で返す。

```
node verifier/p9-cli.mjs 入力.pdf                   # 標準出力に JSON（形は p9-schema.json）
node verifier/p9-cli.mjs 入力.pdf --include-names   # ファイル名そのものも出す（調べるときだけ。記録やログには使わない）
node verifier/p9-selfcheck.mjs                      # 合成 PDF と正解データで、検証器そのものを確かめる
```

終了コード：0 ＝ 読めた（残りがあっても 0）、1 ＝ 使い方の誤り、2 ＝ PDF を読めなかった。

## 検査器から独立していること

- `src/`・`rules/` のコードを import しない。検出ルールは pdf-lib で書く予定なので、検証器は **pdf-lib を使わない**。
- 読み方を2つ持つ。
  1. **バイト列を自分で読む**（主。`p9-pdfbytes.mjs`）：xref を前の版までたどり、いまの版のオブジェクトの表を作る。そこから、名前の木（`/Kids` の入れ子も）・ページの添付ファイルの注釈・関連ファイル（`/AF`）をたどって、中身のストリーム（`/EF`）を集める。表にあるオブジェクトを全部見て、どこからもたどれない中身のストリーム（`/Type /EmbeddedFile`）も集める。
  2. **PDF.js（pdfjs-dist 6.4.299）**（突き合わせ）：`getAttachments`（名前の木）と、ページの注釈（`getAnnotations`）。中身があるかは `getAttachmentContent` で確かめる。安全側の設定（`isEvalSupported: false` など）で使う。
- 「指されていない添付」と `/AF` だけのものは、PDF.js では見えない。そのため、バイト列の読み方を主にした。
- 捨てた案：PDF.js だけで読む。名前の木から外しただけの添付（中身はファイルに残る）を見逃すため。

## 判定

- 1件 ＝ 中身のストリーム1つ。同じ中身を名前の木と注釈の両方が指していれば1件にまとめ、ほかの場所を `also` に入れる。
- 中身のない（外のファイルを指すだけの）ファイル指定、リンクの動作（URL・Launch・GoToR）は、数えない。
- ファイル名は、ファイル指定の `/UF`・`/F` の順で読む（なければ名前の木の鍵）。既定では出さず、字数と拡張子だけを出す。ファイル名に個人名が入ることがあるため。

## 確かめた結果（2026-11-03、Node 24.19.0、Windows）

`node proposals/p9/verifier/p9-selfcheck.mjs` の結果：

- 合成 PDF 20 個すべてで、正解データと合った。漏れ 21 件中 21 件を見つけた。漏れでないもの 15 件中 0 件に反応した。正解にない出力は 0 件。
- 2つの読み方が食い違った PDF は 0 個（名前の木と注釈の分）。
- 壊れた入力など 6 種（空のファイル、PDF でないもの、途中で切れた PDF、入れ子が 5000 段の配列、`/Encrypt` のある trailer、`/Kids` が自分を指す名前の木）で、止まらなかった。輪になった木は、0 件で `ok` を返した。
- 途中で見つけて直したこと：pdfjs-dist 6.4.299 の `getAttachments` は Map を返し、中身（content）を持たない。また、外のファイルを指すだけの注釈も `file` を返す。最初は、ふつうのオブジェクトとして読み、中身の有無を見ていなかったので、食い違いが出た。Map として読み、`getAttachmentContent` で中身を確かめるように直した。

## できないこと（限界）

- **前の版にだけある添付**（増分更新で、同じ番号のオブジェクトを上書きして消したもの）は見ない。P5（旧版の残存）の範囲。いまの版の表にまだ載っている「外しただけ」のものは、`unreferenced` として数える。
- 中身のストリームに `/Type /EmbeddedFile` がなく、どこからも指されていないものは見つけない（`/Type` は省いてもよい決まりのため）。
- 圧縮は Flate だけを解く。ほかの圧縮のオブジェクトストリームの中は読めず、その PDF は `unreadable` にする（0 件とは数えない）。
- 添付の中身の中（添付した PDF の中の添付など）は見ない。
- リッチメディア・3D・音などの注釈の中身（`/RichMediaContent` など）は、いまは見ない。
- 暗号化された PDF は `encrypted` で止める。
- 時間の上限は、PDF.js の読み方に 20 秒。バイト列の読み方は、xref の区切り 1000 個、入れ子 64 段、名前の木の節 1 万、ページ 1 万、オブジェクト 20 万、解いたストリーム 64 MB までで止める。
