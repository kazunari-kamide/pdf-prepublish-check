# 合格基準：P6（見せかけの黒塗り）

機械で読む版は `rubric/p6.json`。2つの中身は同じにする。値を変えるのは人だけ（CLAUDE.md §2-3）。

## 1. 合格の条件（2026-11-02 決定）

合成 PDF（`fixtures/p6/`）全体で、次の3つを**すべて**満たすこと。

| 条件 | 値 |
|---|---|
| 検出率 | 95% 以上 |
| 誤検知率 | 5% 以下 |
| 片付けたあとに残る情報 | 0 件 |

- **判定は全体の数字で行う**（2026-11-03 決定）。字の層だけでなく、画像の層・注釈で覆った型も、最初から分母に入れる。
  - 最初の検出ルールは字の層だけを見る。そのため、画像の層・注釈の型が漏れの 5% を超えるあいだは不合格になる。これは意図したもの（あとで見つけられるようになるかを試すため）。
- **型ごとの内訳は、合否にかかわらず、いつも並べて出す。** 件数が 0 の型も「0 件中 0 件」と出す。

| 内訳の型（層 / 覆っているもの） | 中身 |
|---|---|
| text/fill | 字の上に、濃い塗り（四角・太い線）を重ねた |
| text/image | 字の上に、濃い画像を貼った |
| text/annotation | 字の上に、濃い注釈（四角の注釈・未適用の墨消し注釈）を置いた |
| image/fill | スキャン画像の上に、濃い塗りを重ねた（画像の画素はそのまま） |
| image/image | スキャン画像の上に、濃い画像を貼った |
| image/annotation | スキャン画像の上に、濃い注釈を置いた |

## 2. 数え方

- **1件** ＝ 覆っているもの1つと、その下に残った中身のまとまり1つ。
  - 1つの覆いの下に、字とスキャン画像の両方が残っていれば、字の層で1件・画像の層で1件と数える。
- **検出率** ＝ 見つけた漏れの数 ÷ 正解データの漏れ（`leaks`）の数
- **誤検知率** ＝ 誤検知の数 ÷ 正解データの「漏れでないもの」（`negatives`）の数
  - 誤検知の数 ＝ 漏れでないものに重なった報告の数 ＋ 正解のどれにも重ならなかった報告の数
  - 正解にない所への報告も、誤検知として数える（数えないと、何でも報告すれば検出率だけが上がるため）。そのため、誤検知率は 100% を超えることがある。
- **片付けたあとに残る情報** ＝ 片付けたあとの PDF を検証器にかけたときの `items` の数の合計
  - 検証器が「読めない」（`status` が `ok` でない）と返したもの、省いたページ（`skipped_pages`）があるものは、0 件とは数えない（不合格）。

## 3. 照らし合わせ方

報告（検出ルールの「見つけた所」を、検証器の出力と同じ形にそろえたもの）と正解データを、次の条件で1対1に結ぶ。

1. 同じページであること
2. 同じ層（`text` か `image`）であること。漏れでないもの（`negatives`）には層がないので、2 は見ない
3. 箱の重なりが 50% 以上であること。重なり ＝ 2つの箱の重なった面積 ÷ 小さいほうの箱の面積
   - 小さいほうで割るのは、覆いの箱を返す版と、覆われた字の箱を返す版の、どちらも同じ条件で測るため。
4. 1つの正解には、重なりがいちばん大きい報告を1つだけ結ぶ

- 覆っているものの種類（`cover`）と、残っている字数は、合否には使わない。検証器そのものの確かめ（`verifier/selfcheck.mjs`）では、これも一致するかを見る。
- 座標は、ページの既定の座標（ポイント。左下が原点。ページの回転 `/Rotate` はかけない）。

## 4. 採点の流れ（PRD §2-3-1）

1. 片付ける前の合成 PDF を検証器にかけ、正解データと合うかを確かめる（`node verifier/selfcheck.mjs`。検証器そのものの確かめ）。
2. 片付けた PDF を検証器にかけ、残っている件数を数える。片付けたのが検査器でも「1回の指示で作った版」でも、同じ手順で測る。
3. 検出率・誤検知率は、それぞれの版の報告を検証器の出力と同じ形にそろえ、上の照らし合わせ方で測る。そろえる変換は採点する側（eval）に置き、`verifier/` には置かない。

## 5. 採点用データ（非公開）

ループには読ませない。人が手元で回し、件数だけを記録する。合格ラインは設けない。

## 6. まだ決めていないこと（案）

- 片付けたあとのページが「使える」ことの条件。たとえば、覆いの外の字が片付けの前と同じだけ取り出せること、ページ数が変わらないこと。いまの条件だけだと、ページを全部消しても「残り 0 件」になる。入れるかどうかは人が決める。
