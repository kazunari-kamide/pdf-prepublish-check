# 検出ルール：しおりの題と、代わりの文字 `alt-text`

ページには描かれていないが、画面の横・読み上げ・コピーで取り出される字を、**数と場所**で返す。型は P7（隠れたテキスト）の仲間として扱う【仮】。

| 種類（`kind`） | 何か | 画面の深刻度【仮】 |
|---|---|---|
| `actual_text_diff` | ページの中の `/ActualText`（マーク付きの中身。名前つきの属性も）が、中で描いた字と違う | 中 |
| `outline` | しおり（`/Outlines`）の題の数と字数（入れ子もたどる） | 低（確認してほしい所） |
| `alt` | 構造の `/Alt`・`/ActualText`、字を描いていない所（画像など）の `/ActualText` | 低（アクセシビリティで推奨されるので危険にしない） |

- 比べるときは、NFKC で全角・半角をそろえ、空白を除く。同じなら `notCounted.sameText`（合字・異体字を直す使い方）。
- 字の中身が分からない書体（ToUnicode なし）の上の `/ActualText` は、比べられないので `notCounted.unknownFont`。
- 1.1.0 から（2026-11-05。見ないで作るテスト集の T63・T65）：しおりの題・構造の `/Alt`・`/ActualText` のうち、ページに描いた字（中身の分かるもの。部品の中も）の中に、NFKC でそろえて空白を除いた形でそのまま出てくるものは数えない（`notCounted.inBody`）。見出しと同じ題、図の見える説明と同じ `/Alt` は、隠れた字ではないため。字の中身が分からない書体の字は比べられないので、これまでどおり数える。

## 確かめたこと

## できないこと（限界）

- 注釈の見た目の中の `/ActualText` は見ない。入れ子の `/ActualText` は外側のものにまとめる。
- 1 ページの命令は 300 万個まで、しおりは 10 万個まで、構造の要素は 20 万個まで。
