# ページの縮小画像と、知らせるだけのもの `extras`

## ページの縮小画像（26 項目の 24）

ページに `/Thumb` が付いているページを、ページ・大きさで返す。型は P5（旧版の残存）の仲間【仮】、画面の深刻度は低【仮】。

- **1.1.0 から、いまのページの見た目とおおまかに比べる**（`thumb-compare.ts`。見ないで作るテスト集の T20）。結果は `compare`。
  - ページを縮小画像と同じ大きさのマス目にし、白い紙の上に、ページの画像（縦横に置いた、pdf-lib で解けるもの）を描く。字の帯（字の位置から右の端まで）・塗り・線の箱は「分からない所」にして比べない。
  - 縮小画像の作り方（1点を拾う・平均する）は分からないので、マスの下の画素の明るさの幅（マスを半分ずつ広げた範囲の、いちばん暗い〜明るい）を持ち、縮小画像のマスがその幅から 0.2 より外れたら「違うマス」とする。
  - 違うマスが、分かるマスの 2% 以下なら `same`（画面に出さない）、超えたら `differs`（画面では「高」）。分かるマスが 3 割より少ない・部品や切り抜き・埋め込みの画像があるときは `unknown`（これまでどおり「低」で、確かめてくださいと添える）。値はすべて【仮】。
  - 合成 PDF のすべて（401 個）で、縮小画像のあるものは T20 の2つで、隠しは `differs`、対照は `same`。
- 片付け（`sanitize/`）は、すでに縮小画像を外している。

## お知らせ（26 項目の 26）

漏れとは言い切れないので、画面の「お知らせ」（`kind: "info"`）として出す。

- `xfa`：XFA のフォーム（`/AcroForm /XFA`）。中の入力した値（`xfa:datasets`）の字数も数える（値は返さない）。
- `c2pa`：C2PA（画像の来歴の情報）。JPEG の APP11 の JUMBF に `c2pa` があるもの、`/AFRelationship /C2PA_Manifest` の添付、種類が `application/c2pa` のストリーム。

## できないこと（限界）

- XFA の中のスクリプトは見ない。
