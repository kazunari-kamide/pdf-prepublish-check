# 書体に残った字形 `font-glyphs`（26 項目の 22）

埋め込みの書体（部分埋め込み）に、ページのどこにも描かれていない字の形が残っているものを、**数だけ**返す。前に書いてあって消した字（黒塗りの下だけにあった字など）の手がかりになる。型は P7 の仲間【仮】、画面の深刻度は中【仮】。

- 見る書体：Type0 の CIDFontType2（TrueType）で、名前が部分埋め込みの印（`ABCDEF+`）で始まり、Identity-H・V のもの。CIDToGIDMap は Identity かストリーム。
- 描かれた字：ページ・部品（フォーム XObject）・注釈の見た目（/AP）の、字を描く命令の 2 バイトのコード。複合の字形の部品も「描かれた」に入れる。
- 数えない：字の形 0（.notdef）、形の無い字（空白など）。**余りが 3 個より少ない書体は出さない**（合字・記号など、ふつうに少し余るため。`belowThreshold` に数える）。

## 確かめたこと

- 合成 PDF 5 件（隠しあり 2・対照 3。`eval/cases/font-glyphs.ts`）：検出 2/2、誤検知 0。
- 書体は、リポジトリにある BIZ UDゴシック（SIL Open Font License。P6 の合成 PDF と同じもの）。pdf-lib は部分埋め込みの書体に印を付けないので、合成 PDF の側で、Word などと同じ形の名前（`KAKUUA+…`）に書き換えている。

## できないこと（限界）

- 余った字形が**どの字か**は出さない（字の形を描いて見比べないと分からない）。
- CFF（OpenType の FontFile3）・Type1・Type3・1 バイトの TrueType は見ない（`skippedFonts`）。
- 部分埋め込みの印の無い書体は、全部を埋め込んだものとみなして見ない。
- 日本の公開 PDF の束での誤検知（ソフトがふつうに余分な字形を入れる場合）は、まだ測っていない。

## 1.1.0（2026-11-05）：Type3 の書体

- Type3 の書体（字の形を PDF の命令で描く書体）も見る。`/CharProcs` の字形のうち、塗る・線を引く・画像・字の命令があるもので、`/Encoding /Differences` でどの描いた字（1 バイトのコード）からも引かれていないものを数える。Type3 にはサブセットの印が無いので、印は見ない。
- 合成 PDF：7 件（隠しあり 3・対照 4）で、検出 3/3、誤検知 0。

## 1.2.0（2026-11-05）：印の無い部分埋め込み

- 名前に部分埋め込みの印（`ABCDEF+`）が無い TrueType も見る（pdf-lib などは印を付けない）。
- 印が無いときは、書体の中身で部分埋め込みかを見分ける。字の対応表（`cmap`）と名前の表（`name`）が無ければ、部分埋め込みとして数える（部分埋め込みの道具は、PDF で要らないこの 2 つを落とす。pdf-lib の部分埋め込みも同じ形）。`subsetBy: "tables"`。
- `cmap` か `name` がある印の無い書体は、全部を埋め込んだものとみなして見ない（`fullFonts` に数える）。全部の字形が「余り」になってしまうため。
- 合成 PDF：9 件（隠しあり 4・対照 5）で、検出 4/4、誤検知 0。対照に、印の無い部分埋め込みで使う字形だけのもの（`fg-c05`）と、全部の埋め込み（`fg-c06`）を足した。前の対照 `fg-c03`（印の無い部分埋め込みに余りがあるもの）は、隠しの件 `fg-l04` にした。
- 今ある合成 PDF 370 件（`fixtures/` と見ないで作るテスト集）にかけて、片付ける前に出たのは、見ないで作るテスト集の T69 の 1 件だけ（前と同じ）。
- 片付け（`sanitize`）は黒塗りの下の字を消すが、書体の字形は残すので、片付けたあとの P6 の合成 PDF 13 件で、消した字の字形が出る（`tests/sanitize-reinspect.test.ts` の `KNOWN_LEFT`）。
- 限界：`cmap` を残す部分埋め込みの道具で作った、印の無い書体は見ない（全部の埋め込みと見分けられないため）。
