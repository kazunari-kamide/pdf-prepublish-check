# 検出ルール：P12（スクリプト・外部動作）`p12-actions`

PDF を入れると、文書の JavaScript と、開いた・閉じた・印刷したときなどに自動で動く動作を、**有る・無いと場所**で返す。漏れではないので、画面の深刻度は「低」（安全上の注意。用語集 §3）。JavaScript の中身は返さない（字数だけ）。実行もしない。

```ts
import { detectP12Actions } from "./rules/p12-actions/index.ts";
const report = await detectP12Actions(bytes);
```

| 場所（`where`） | 何か |
|---|---|
| `names` | 文書の JavaScript の一覧（カタログの `/Names /JavaScript`） |
| `open_action` | 開いたときの動作（`/OpenAction`。続きの動作 `/Next` も） |
| `document_aa` | 閉じる前・保存の前・印刷の前など（カタログの `/AA`。`trigger` に鍵） |
| `page_aa` | ページを開いた・閉じたとき（ページの `/AA`） |
| `annotation` | 注釈を押したときなど（`/A`・`/AA`） |
| `field` | フォームの欄（ウィジェットと欄の `/AA`、ボタンの `/A`） |
| `other` | どこからも指されていない JavaScript の動作 |

## 数える動作と数えない動作

- **どこでも数える**：`javascript`・`submit_form`（入力を送る）・`import_data`。
- **自動で動く所だけ数える**：`launch`（ほかのファイルやプログラムを開く）・`remote_goto`（別のファイルへ移る）・`uri`（ウェブのページを開く）・そのほかの動作（`other_action`）。
- **数えない**（`notCounted`）：同じ文書の中へ移る（`GoTo`・行き先の配列）・名前つきの動作（次のページなど）・押したときだけ動くリンク（URL・別のファイル・ファイルを開く）。
  - 押したときだけ動く `launch`・`remote_goto` は、最初は数えていた。今ある P9 の合成 PDF（外のファイルを指すリンク）で 2 件出たため、ふつうのリンクとして外した（2026-11-05）。

## 確かめたこと

- 合成 PDF 12 件（隠しあり 8・対照 4。`eval/cases/p12.ts`。`npm run eval:new`）：検出 10/10、誤検知 0。

## できないこと（限界）

- XFA のフォームの中のスクリプトは見ない。
- 注釈の外にある、直接書かれた動作の辞書（どこからも指されていないもの）は、間接オブジェクトのときだけ見つける。
- 動作は 100,000 個まで、オブジェクトは 1,000,000 個まで見る。超えたら `limits` に出す。

## 1.1.0（2026-11-05）：押して開くウェブのリンク

- 押したときに外のウェブのページを開くリンク（注釈の `/A`・フォームのボタン）の `uri` を、押したときだけ動く所でも数える。画面では低の「確認してほしい所」（行き先が庁内や作業中の場所でないか）。
- 別のファイル・プログラムを開くリンク（`GoToR`・`Launch`）は、いままでどおり数えない（`notCounted.link`）。
- 片付けはリンクを消さないので、リンクのある PDF は、片付けたあとにもこの件が残る（C・B に決めてもらうこと）。

## 1.2.0（2026-11-05）：気をつける行き先のリンクだけ

- 押したときだけ動くリンク（注釈・フォームのボタン）の `uri` は、行き先が気をつける所（`cautionUri`）のときだけ数える。ふつうの https・mailto・tel のリンクと、相対の場所は数えない（`notCounted.link`）。
- 気をつける所：暗号化されない http、ウェブ以外の種類（file・smb・javascript・data など）、点の無いホスト名・IP アドレス・`.local` などの内向きの名前、ログイン情報（`user:pass@`）の入った URL。
- 自動で動く所（開いたとき・ページの /AA など）の動作は、いままでどおり行き先にかかわらず数える。
- 片付けはリンクを消さないが、ふつうの https のリンクは数えないので、片付けたあとの「残り」にもならない。
- 限界：公開の https の場所でも、作業中の場所（共有の下書き・個人の保存先など）かどうかは、字の形では分からないので数えない。
