# P3 他組織名の混入 `p3-orgs`

ほかの団体の書類（様式）をひな形にして作ったとき、文書情報や XMP の題・作成者欄に、元の団体の名前が残る型。題などの団体名らしい語が、本文の団体名らしい語と違うものを、**字数だけ**返す（値は返さない）。画面の深刻度は中【仮】。

## 見分け方

団体名の一覧は持たない。字の並びの形だけで見る。

- 日本語：`rules/props` の `orgMarks` のうち、〇〇市・町・村・区・県・都・府・北海道と、株式会社などの会社・法人の言葉のあるもの。課・室・係・局・部・庁は、同じ団体の中の部署のことが多いので比べない。
- 英語：大文字で始まる語のあとに City・Town・Village・Ward・Prefecture・County が続くもの。会社は Inc.・Ltd.・Co.・Corporation・Corp.。比べるのは、後ろの言葉と、その直前の 1 語。
- 団体名の頭の日付の切れ端は外して比べる（1.0.1 から）。「令和6年9月架空町議会」は数字の手前で切れて「月架空町」になるため、頭の年・月・日・号・回と、漢数字のすぐあとのものを外す（「九月架空町」→「架空町」）。
- 見る欄：`/Info` の Title・Subject・Author・Keywords、XMP の dc:title・dc:description・dc:creator・pdf:Keywords。
- 本文：ページの字（`rules/common/page-text.ts`）。

## 出す条件

- 本文に団体名らしい語が 1 つ以上あり、題などの団体名らしい語が、本文のどこにも無いとき。
- 本文に団体名らしい語が無いときは、比べられないので出さない（`notCompared` に数える）。

## 確かめたこと

- 合成 PDF 4 件（隠しあり 2・対照 2。`eval/cases/p3.ts`）：検出 3/3、誤検知 0。
- 見ないで作るテスト集の T11：隠しの件 0/1 → 1/1。

## できないこと（限界）

- 本文に、元の団体と今の団体の両方の名前があると、出さない（本文にある名前とみなすため）。
- 本文の字を読めない PDF（スキャンだけ・ToUnicode の無い書体）では、比べられない。
- 「〇〇町内会」「〇〇市場」のような言葉は、`orgMarks` の除外の一覧で外しているが、一覧にない言葉は団体名とみなすことがある。
- 日本の公開 PDF の束での誤検知は、まだ測っていない。
