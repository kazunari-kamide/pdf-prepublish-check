# 検出ルール：P8（注釈・コメント）

PDF を入れると、注釈に残った**作成者欄（`/T`）**と、内容（`/Contents`）・件名（`/Subj`）・リッチテキストの内容（`/RC`）を返す。**値そのものは返さない**（欄・字数・注釈の数・ページだけ）。

Acrobat などで注釈を付けると、作成者欄に、付けた人のログイン名（姓のローマ字など）が入る。文書情報（P1 の `/Info`）を消しても、注釈の作成者欄は残る。見つける段（公開 PDF 100 件を、型のヒントなしで Claude に調べさせた回）で見つかった型。2026-11-04、人の決定で P8 に入れた。

```ts
import { detectP8Annot } from "./rules/p8-annot/index.ts";
const report = await detectP8Annot(bytes);                          // 欄と字数だけ
const report2 = await detectP8Annot(bytes, { includeValues: true }); // 値そのものも返す（調べるときだけ。記録やログには使わない）
```

| 項目 | 中身 |
|---|---|
| `findings[].field` | `T`・`Contents`・`Subj`・`RC`・`AP`（1.1.0。隠しの注釈の見た目の中の字） |
| `findings[].hidden` | 隠しの印（`/F` の Hidden＝2・NoView＝32）のある注釈か（1.1.0） |
| `findings[].chars` | 値の字数（前後の空白を除く。`RC` はタグを外した字） |
| `findings[].annotations` | この値を持つ注釈の数 |
| `findings[].pages` | この値を持つ注釈のあるページ |
| `hiddenAnnotations` | 見た注釈のうち、隠しの印のある注釈の数（1.1.0） |
| `notCounted` | 値はあったが、決まり文句として数えなかったもの（欄・理由・注釈の数） |
| `limits` | 上限を超えて見なかったページ |

## 数え方

- 1件 ＝ 欄と値と隠しの印の組み1つ。同じ欄に同じ値を持つ注釈は、何個あっても1件にまとめる（全注釈で同じ作成者なら1件）。
- 見る注釈：ページの `/Annots` にあるもの。隠した注釈も見る（ファイルには残っているため）。同じ注釈を2つのページが指していても1回だけ数える。
- **隠しの注釈（1.1.0）**：隠しの印（Hidden・NoView）のある注釈は `hidden: true` の別の件にする（画面に見えないため、画面の深刻度を「高」にする【仮】）。読み取り専用（64）・ロック（128）・印刷（4）の印は隠しではない。
- **見た目の中の字（1.1.0）**：隠しの注釈だけ、見た目のストリーム（`/AP` の `/N`。状態ごとの辞書なら全部）に描かれた字（`Tj`・`TJ`・`'`・`"`。描画モード 3・7 は除く。中の部品もたどる）を数える（`field: "AP"`）。スタンプ注釈で、字が `/Contents` になく見た目の中だけにある型。隠しでない注釈の見た目は、画面に見えている字なので数えない。
- 見ない注釈：フォームの欄（`/Widget`。`/T` は欄の名前で、人ではない）、吹き出し（`/Popup`。親の注釈の欄を写したもの）。
- **数えない値**（見つける段の誤検知の型）：作成者欄の「Author」「user」「Administrator」「admin」「ユーザー」「ユーザ」（大文字と小文字は区別しない）と、数字だけの値（共通の ID）。`notCounted` に回す。
- 値の文字は、P1 と同じ読み方（`decodeTextBytes`。UTF-16BE・UTF-16LE・UTF-8・PDFDocEncoding）で読む。`/RC` は文字列かストリームの XHTML で、タグを外し、よく使う文字参照を戻した字を数える。

## できないこと（限界）

- **部署名（「総務課」など）と個人名は見分けない。** どちらも数える。画面では「意図したものでなければ」と添える（用語集 §6）。
- 件名（`/Subj`）は、注釈の道具の名前（「Rectangle」「長方形」など）が自動で入ることが多い（推測。実物では確かめていない）。いまは数える。誤検知が多ければ、決まり文句に足す。
- 注釈の返信（`/IRT`）・状態（`/State`）・作った日時（`/CreationDate`・`/M`）は見ない。
- 1ページの注釈は 10,000 個まで見る。1つの欄は 100,000 字まで読む。
- パスワードが要る暗号化 PDF は読まない（`encrypted`）。パスワードなしで開ける暗号化は、共通の入口（`rules/shared/load.ts`）で復号して読む。

## 1.2.0（2026-11-05）：見た目だけの字

- 隠しでない注釈でも、`/Contents` が無く（空で）、字が見た目（`/AP`）の中だけにあるもの（スタンプなど）は、`field: "AP"`・`hidden: false` で数える。画面では低。
- 注釈の一覧には何も出ないのに、注釈を消さないかぎり字として取り出せるため。`/Contents` のある注釈の見た目は、同じ字を二重に出さないよう数えない。リンクは見ない。
- 前の対照 p8-c01（読み取り専用・ロックのスタンプ）はこの形なので、隠しとしては数えないことを確かめる件（`p8-l07`）に変えた。
