# プロパティの一覧と、文書情報と XMP の食い違い `props`

## `listProperties(bytes)`（26 項目の 20）

文書情報（`/Info`）と文書全体の XMP の**すべての欄を、中身ごと**返す。プロパティについては「値を画面に出さない」決まりを外す（26 項目の 20。値は利用者の画面にだけ出て、外には出ない）。画面（B の持ち場）が一覧を作り、その場で「消す」へ案内する。ここは関数まで。

- 返すもの：`{ source: "info" | "xmp", name, value, marks }`。
- `marks`：値の中の団体名らしい語の位置（`orgMarks`）。**団体名の一覧は持たず、比べもしない。** 字の並びの形だけで付ける。
  - 〇〇市・町・村・区・県・都・府・課・室・係・局・部・庁（前に漢字・カタカナが 1 字以上）。〇〇道は「北海道」だけ。
  - 株式会社・有限会社・合同会社・一般社団法人などと、その前後の漢字・カタカナ。
  - 対照（印を付けない）：市場・町内・都合・地区・全部・水道・都道府県・市町村・教室・部分・課題・係数・道路・都市など（`tests/props.test.ts`）。
- 記録やログには使わない。

## `detectInfoXmpDiff(bytes)`（26 項目の 25）

作成者・タイトルなどが文書情報と XMP の両方にあって、値が違うものを返す（片方だけを直して古い値が残った疑い）。値は返さず、字数だけ。

- 組み：Title↔dc:title、Author↔dc:creator、Subject↔dc:description、Keywords↔pdf:Keywords、Creator↔xmp:CreatorTool、Producer↔pdf:Producer。
- NFKC と空白をそろえて比べる。XMP に複数の値があるときは「; 」「, 」「 」でつないだもの、またはどれか 1 つと同じなら、同じとみなす。
- 片方にしか無い欄は出さない。画面では P1・中【仮】。

## できないこと（限界）

- 前の版の文書情報・XMP は見ない（P5 の範囲）。部品の XMP は一覧に入れない。
- 印は形だけなので、団体でない言葉にも付くことがある（例：「準備室」）。
