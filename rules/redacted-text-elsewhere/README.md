# 塗った字が、ほかの所に出ている（`redacted-text-elsewhere`）

黒く塗った所の下に字が残っていて、**その字と同じ並びが、同じ書類の塗られていない所にも出ている**所を返す。型は P6（見せかけの黒塗り）の仲間【仮】、画面の深刻度は高【仮】、いつも「確かめてください」。返すのは、塗った所のページ・箱・字の数・いちばん長く一致した字の数と、出ている所の種類（ページの本文・文書情報・XMP・しおり・注釈・フォームの値）とページ番号だけ。**字そのものは返さない**（画面の検査の Worker が頼んだときだけ、画面の中で伏せて出す）。

## なぜ別のルールか

- `p6-text`：黒い四角の下に字が残っていることを見る。「整える」で四角の下の字を消すと、もう当たらない。
- ところが、同じ字が別の段落・別のページ・しおりなどに塗られずに出ていると、四角の下の字を消しても、情報は読めたままになる。整えたあとの読み直しが「0 か所」になっても漏れている。このルールは、そこを止める。

## 見つけ方（決定的。字の意味は読まない）

1. 塗った下の字を集める。
   - `p6-text` の文字の層のうち、濃い覆い（黒塗り）で、確からしさが `high` のものの下の字。濃くない不透明な覆い（`coverTone: opaque`。スライドの地や色の帯など）と、`check`（見出しの帯・番号札の形など）の下の字は使わない。実物の束では、どちらも見出し・表の欄の名前がほかのページにも出る形の当たりばかりだった。
   - `p7-hidden` の `same_color` のうち、`under: "dark"` のもの（黒い四角を描いたあとに、同じ黒で字を重ねた形。見た目は黒塗り。`p6-text` は「上の字」として数えない）。`p7-hidden` 1.8.0 で、この印と、下の塗りの箱 `underBox` を足した。
     - 下の塗りが字を囲む程度の大きさのときだけ使う：塗りの箱の高さが字の箱の 1.6 倍まで、面積が 4 倍まで。実物の A1 は高さ・面積とも約 1.3 倍、誤検知の形（濃い帯・背景の上の黒い字）は高さ 2〜8 倍だった。
2. 字を正規化する：NFKC、空白（全角も）と ■□▪▫●◆◇ を外す。1 件あたり 400 字まで。
3. 塗られていない所の字も同じく正規化する。
   - ページの本文：字の箱の中心が、1 で使った塗りの箱か `p6-text` が見つけた覆いの箱の中にある字は外す。行はつなげて読む（行をまたいだ並びも見る）。
   - 文書情報（/Info）、XMP（タグを外した字）、しおりの題、注釈の /Contents・/T・/Subj、フォームの欄の /V・/TU。
4. 塗った下の字の中の、`minChars`（3【仮】）字以上の並びで、字（漢字・かな・ローマ字。`\p{L}`）を 1 字以上ふくむものが、3 の中にそのまま出ていれば 1 件にする（数字と記号だけの並びは数えない）。同じページ・同じ箱は 1 件にまとめる。

## 「整える」のあと

整えたあとの PDF には、もう四角の下の字が無いので、整える前の検査で集めた「塗った下の字」を使う。字は検査の Worker（`src/worker/inspect.worker.ts`）の中にだけ覚え、整えたあと・小さくしたあとの読み直し（`after`）で、整えたあとの PDF の塗られていない所を探す。画面・ネットワーク・報告書には出さない。ファイルが変わると Worker ごと作り直すので、前のファイルの字は残らない。

読み直しで当たれば、ほかの「残っている所」と同じく、保存の前に止まる。出ている所も自分で黒塗りして整え直すと、当たらなくなる。

## 上限

ページ 500（`MAX_TEXT_PAGES`）、1 ページの命令 100 万・字 10 万（`PAGE_TEXT_LIMITS`）、塗られていない所の字の合計 300 万字、しおり・注釈・フォームの欄 2 万。読めなかったページは `skippedPages` に入れ、画面で「調べていません」と知らせる。

## 画面の検査での読み方

画面の検査（字の中身を頼む検査）では、`p6-text`・`p7-hidden` の報告を 1 回だけ作り、このルールと分け合う（`src/inspect/rules.ts` の `runP6`・`runP7`）。検査の Worker の時間の上限（60 秒）の中で、同じ PDF を 2 回読まないため。コマンドの道具など、字の中身を頼まない検査では、このルールの中でもう一度読む。

## 合成 PDF

`eval/cases/redacted-text-elsewhere.ts`（隠しあり 4・対照 6）。字のあとに四角を重ねた形と、四角のあとに黒い字を重ねた形、出ている所が別のページ・同じページ・文書情報・注釈のもの。対照は、ほかに出ない・数字だけ・正しい墨消し・白い地の上の白い字・両方とも塗った・背の高い黒い帯の上の黒い字。中身はすべて架空。

## 分かっている限界

- **字の意味は読まない。** 同じ並びかだけを見るので、決まり文句・欄の名前・日付などがたまたま同じでも出す（いつも「確かめてください」）。反対に、言い換え・略し方・読み方の違い（「大字」を付けない、漢数字と算用数字など、NFKC で同じにならないもの）は見ない。下の字が本当に消えていて、同じ情報が言い換えで出ている形（調べた束での A2）は、このルールでは見つからない。
- **塗った下に字が残っているときだけ** 比べる。正しく墨消しした所（下に字が無い）は、何を塗ったかが分からないので比べない。
- 3 字の並びで比べるので、ローマ字の短い語（英語の文書など）では、関係のない語が合うことがある。実物の束で測ったのは、ほとんど日本語の書類。
- しきい（3 字・1.6 倍・4 倍）は、人が確かめた実物（A1 の 17 書類）と、誤検知を数えた束（holdout2・holdout3・300 件）で決めた。誤検知の束は、しきいを決めるのにも使ったので、「まだ使っていない束」での数ではない。
- スキャンの画像の中の字（OCR の層の無いもの）は読まない。
