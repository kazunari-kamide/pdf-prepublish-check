# 画面の案（選ぶ前の見本）

検査器の画面の案を3つ並べる。どれも**動かない見本**で、項目と数字は架空のもの（実在の PDF・団体・人は出てこない）。
選ばなかった案も、ここに残す。選んだ案は、`design/`（`tokens.css` と `design/README.md`）に決まりとして移してから、画面（`index.html`・`src/style.css`）に当てる（CLAUDE.md §6）。

ビルド（`npm run build`）には入らない（入口は `index.html` だけ）。ブラウザでファイルを直接開いて見る。

| 案 | ファイル | 考え方 | ベース色 | アクセント色 | 書体（見出し／本文） |
|---|---|---|---|---|---|
| A 検査票 | `a-kensahyo.html` | 役所の検査票のような表が主役。左に一覧、右にページ。印刷しても読める | `#1F2A37` 墨紺 | `#B42318` 朱 | 明朝／ゴシック |
| B ページが主役 | `b-page-first.html` | PDF を見る道具に近い形。左にページの一覧、中央に大きなページ、右に見つかった所 | `#263238` 青墨 | `#C2410C` 柿色 | UD ゴシック／UD ゴシック |
| C 手順の帯 | `c-omamori-steps.html` | 「選ぶ → 確かめる → 片付ける → 読み直す」の帯を上に置き、結果を「お守りの種類」（型）ごとに並べる。見つからなかった種類も並ぶ | `#2B2A28` 墨 | `#A3201B` 紅 | 明朝／ゴシック |

どの案にも共通すること：

- 危ない所は、色だけで示さない。番号の札・「▲ 高」などの文字・枠の形でも示す。
- 字の中身は出さない。字数と場所だけ。
- 「片付ける」は押せない形。片付けたあとの「全部緑」は見本として置いた。
- 緑（片付いた所）は、2色（ベースとアクセント）の外の「状態の色」として置いた。2色の決まりとの関係は、決めてほしいこと。
- 書体は見本では端末の書体を使っている。決めたら、ライセンスを確かめてリポジトリに同梱する（外から読み込まない。CLAUDE.md §2-1）。
